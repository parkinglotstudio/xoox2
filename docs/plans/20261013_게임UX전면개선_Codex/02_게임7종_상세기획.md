## p01 · 마지막 등불

- 유형: 정화 코어 방어
- 이야기: 숲을 밝히는 정화 코어가 꺼지기 직전입니다. 방어 시설을 세우고 세 차례의 침입을 막아 마을의 길을 다시 여세요.
- 목표: 코어를 지키고 마지막 보스를 정화하세요.
- 예상 한 판: 2~3분 (아래 검수 보고서의 자동 플레이 시간과 구별)
- 출발 장비: 화염 바주카 Lv2 + 기본 공격. 기본 쌍권총에 더해 적 무리를 자동으로 폭발시킵니다.
- 조작: WASD / 드래그 이동 · 빛나는 칸을 눌러 건설
- 성패: 3번의 스폰을 끝내고 모든 적·보스를 정화하며 코어가 생존. 코어 또는 캐릭터 HP 0이면 실패.

### 플레이 순서

1. 방어 시설을 설치하세요
2. 서로 다른 길로 오는 적을 막으세요
3. 마지막 보스까지 정화하면 성공

### 기믹·알림

빨간 길은 다음 침입 방향입니다. 느린 범위 포탑과 빠른 직접 포탑을 섞으세요.

- 0초 기획 기준: 첫 번째 침입 — 정면의 약한 무리를 시원하게 정화하세요.
- 35초 기획 기준: 측면 침입 — 새 진입로가 열립니다. 준비 시간에 시설을 보강하세요.
- 80초 기획 기준: 코어 최후 방어 — 보스의 빨간 예고 구역을 피하면서 코어를 지키세요.

## p02 · 숲의 파수꾼

- 유형: 정화 코어 방어 · FPS
- 이야기: 루온의 눈으로 숲을 바라봅니다. 쌍권총과 같은 방어 시설을 사용해 마을로 향하는 침입을 막으세요.
- 목표: 시설과 쌍권총으로 세 차례의 침입을 막고 코어를 지키세요.
- 예상 한 판: 2~3분 (아래 검수 보고서의 자동 플레이 시간과 구별)
- 출발 장비: 번개 바주카 Lv2 + 기본 공격. 범위 정화는 자동 지원. 이동 · 시점 · 사격 버튼으로 코어를 지키세요.
- 조작: 왼쪽 이동 패드 · 오른쪽 시점 패드 · 사격 버튼 꾹 누르기 / PC: WASD · 오른쪽 드래그 · Space
- 성패: p01과 같은 3웨이브·시설·HP·보스 판정. 카메라와 조작만 FPS.

### 플레이 순서

1. 출발 기술은 이미 장착됨 · 추천 시설을 배치하세요
2. 전투가 시작되면 FPS로 전환 · 왼손 이동, 오른손 시점
3. 중앙에 적을 넣고 사격 · 코어 HP가 0이면 실패

### 기믹·알림

보조 사격은 처음에 켜져 있습니다. 버튼으로 끄면 꾹 누른 동안 직접 사격합니다. 코어 방향과 후방 경고를 확인하세요.

- 0초 기획 기준: 파수 시작 — 적을 조준점 안에 넣으면 자동 사격합니다.
- 35초 기획 기준: 양쪽 길 경계 — 시설은 다른 길을 맡깁니다. 시야 밖 위협을 확인하세요.
- 80초 기획 기준: 보스와 대치 — 공격 예고가 보이면 옆으로 이동하세요.

## p03 · 숲이 깨어나는 시간

- 유형: 정화숲 대생존
- 이야기: 오염된 숲에 정화의 길을 냅니다. 발밑과 정화한 몬스터 주변에서 풀빛과 작은 꽃이 돌아옵니다. 힘을 키워 숲의 수호자를 되찾으세요.
- 목표: 세 단계의 침입을 견디고 최종 보스를 정화하세요.
- 예상 한 판: 약 3분 (아래 검수 보고서의 자동 플레이 시간과 구별)
- 출발 장비: 서리 조각 Lv2 + 기본 공격. 수정이 몸 주위를 돌며 적을 타격합니다. 이동하며 땅을 되살리세요.
- 조작: WASD / 드래그 이동 · 공격은 자동
- 성패: 180초에 최종 보스가 출현하고 보스 정화 후 성공. HP 0이면 실패. 이동·처치로 복원하는 땅은 환경 진행 지표이며 추가 승리 장벽이 아니다.

### 플레이 순서

1. 서리 조각이 이미 장착됨 · 걸어 다니며 오염된 땅을 되살리세요
2. 러시 예고를 피해 무리를 한 번에 정화하세요
3. 기술을 강화·진화해 최종 보스를 물리치세요

### 기믹·알림

이동과 몬스터 정화로 땅이 회복됩니다. 출발 기술 + 추가 성장으로 최대 6종을 강화하고 최종 수호자를 정화하세요.

- 0초 기획 기준: 숲의 입구 — 가까운 정화 구슬을 모으며 첫 기술을 확인하세요.
- 40초 기획 기준: 무리의 접근 — 러시 방향을 보고 넓은 통로로 이동하세요.
- 85초 기획 기준: 깨어난 수호자 — 중간 보스와 새 적이 등장합니다. 강화한 기술을 활용하세요.
- 140초 기획 기준: 마지막 정화 준비 — 최종 보스가 곧 등장합니다. 회복 구슬을 남겨 두세요.
- 180초 기획 기준: 최종 수호자 — 붉은 예고를 피하고 수호자를 정화하세요.

## p04 · 수정의 행렬

- 유형: 체인 대열 정화
- 이야기: 오염된 수정 행렬이 마을의 경계로 내려옵니다. 긴 대열을 시원하게 터뜨리고 금빛 보급을 먼저 회수하세요.
- 목표: 모든 대열을 방어선에 닿기 전에 정화하세요.
- 예상 한 판: 2~3분 (아래 검수 보고서의 자동 플레이 시간과 구별)
- 출발 장비: 대열 정화 폭탄 Lv1 + 기본 공격. 기본 연속 사격과 함께 무리 중심을 자동으로 폭발시킵니다.
- 조작: AD / 좌우 드래그 이동 · 전방 자동 사격
- 성패: 6개 대열의 모든 체인 개체를 정화. 개체 하나라도 붉은 방어선에 닿으면 실패.

### 플레이 순서

1. 숫자가 작은 마디부터 터뜨리세요
2. 금빛 보급 마디를 먼저 정화하세요
3. 붉은 방어선을 넘기 전에 행렬을 제거하세요

### 기믹·알림

세 줄 사격·관통·연속 사격은 실제 공격 방식이 다릅니다. 머리가 없어져도 몸통은 계속 이동합니다.

- 0초 기획 기준: 첫 행렬 — 좌우로 움직여 탄환을 대열에 맞추세요.
- 30초 기획 기준: 단단한 마디 — 큰 숫자는 여러 발이 필요합니다. 관통과 연사를 활용하세요.
- 80초 기획 기준: 마지막 행렬 — 금빛 보급과 가까워진 붉은 경계에 집중하세요.

## p05 · 잃어버린 발자국

- 유형: 수색 돌파
- 이야기: 숲 깊숙한 곳에서 반려동물의 구조 신호가 들립니다. 서로 다른 여섯 구역을 지나 마지막 감옥의 봉인을 풀어 주세요.
- 목표: 6개 구역을 돌파하고 갇힌 펫을 구출하세요.
- 예상 한 판: 약 1~2분 (아래 검수 보고서의 자동 플레이 시간과 구별)
- 출발 장비: 번개 사슬 Lv2 + 기본 공격. 여러 적 사이로 번개가 이어집니다. 정화가 끝난 방의 문으로 이동하세요.
- 조작: WASD / 드래그 이동 · 출구는 북쪽의 빛
- 성패: 6개 방 × 각 3무리를 모두 정화하고 북쪽 출구를 통과. 최종 방 보스를 정화해 펫 구출. HP 0 또는 240초 종료 실패.

### 플레이 순서

1. 각 구역의 세 무리를 정화하면 문이 열립니다
2. 웅덩이와 가시의 예고를 피해 이동하세요
3. 마지막 보스를 정화하고 구조 지점에 도달하세요

### 기믹·알림

빈터·바위·기둥·웅덩이·가시·봉인방마다 공략이 다릅니다. 문 위의 빛이 다음 목적지입니다.

- 0초 기획 기준: 구조 신호 추적 — 남은 적을 정화하면 북쪽 문이 열립니다.

## p06 · 함께 돌아가는 길

- 유형: 구출 호위와 탈출
- 이야기: 공중섬 끝에서 구조를 기다리는 펫이 있습니다. 구호 수레로 찾아가 봉인을 풀고 안전한 귀환 거점까지 데려오세요.
- 목표: 구조 현장에서 펫을 구출한 뒤 수레와 함께 귀환하세요.
- 예상 한 판: 약 2분 (아래 검수 보고서의 자동 플레이 시간과 구별)
- 출발 장비: 서리 조각 Lv2 + 기본 공격. 주변 수정이 접근하는 적을 막습니다. 수레 옆을 지키며 이동하세요.
- 조작: WASD / 드래그 이동 · E / 작업 버튼 구조
- 성패: 수레 근처에서 전진 → 구조 거점에서 2.5초 작업 → 구조한 펫과 귀환. 수레/캐릭터 HP 0 또는 300초 종료 실패.

### 플레이 순서

1. 수레 가까이에서 움직이며 적을 막으세요
2. 종점에서 E / 작업 버튼으로 펫을 구출하세요
3. 구출한 펫을 태우고 뒤쪽 귀환 거점까지 호위하세요

### 기믹·알림

수레가 멈춘 이유를 화면에서 알려 줍니다. 멀어짐·적의 저지·구조 대기를 구별하고 갈림길에서 경로를 고르세요.

- 0초 기획 기준: 구호 수레 출발 — 수레 가까이 머무르세요. 적이 붙으면 먼저 정화하세요.

## p07 · 다시 피어나는 섬

- 유형: 정화 복구
- 이야기: 섬의 정화 장치가 멈추면서 땅이 오염되었습니다. 정화석을 모아 세 장치를 복원하고 초록빛이 퍼지는 순간을 함께 보세요.
- 목표: 오염된 땅 45%와 정화 장치 3곳을 복구하세요.
- 예상 한 판: 약 1분 (아래 검수 보고서의 자동 플레이 시간과 구별)
- 출발 장비: 서리 장막 Lv2 + 기본 공격. 정화 장막으로 주변 적을 늦춥니다. 땅과 장치를 직접 복구하세요.
- 조작: WASD / 드래그 이동 · E / 작업 버튼 채집·복구
- 성패: 실제 바닥 셀 45% 이상 정화 + 정화석 채집 + 시설 3곳 각각 3초 작업 복구. HP 0 또는 240초 종료 실패.

### 플레이 순서

1. 서리 장막을 두르고 걸어 다니며 땅 45%를 정화하세요
2. 정화석 2개로 장치 하나를 복원하세요
3. 걸으며 땅을 정화하고 세 장치를 완성하세요

### 기믹·알림

정화석은 한정된 자원입니다. 다음 더미나 미복구 장치를 안내하며 작업 진행도를 표시합니다.

- 0초 기획 기준: 멈춘 정화 장치 — 먼저 반짝이는 정화석을 모으세요.

## 공통 계약

입장 브리핑 → 장착 장비 확인/추가 1선택 → 목표 안내 → 전투와 환경 회복 → 최종 목표 → 모드별 결과/별 → 카드로 돌아가기. 체력과 목표를 항상 보이고 장비 수치·전체 표는 접어서 제공한다. 기본 공격은 연속 사격/재장전, 자동 정화 기술은 별도 CD로 동작한다. p02는 같은 BaseDefense를 상속하여 시설/적/피해 표가 복제되지 않는다. 일반판 최대 Lv14, 기술6종·패시브3종, 성장 선택 최소6초 간격. 모든 기술을 동시에 넣는 기획툴 실험은 캠페인 밖의 별도 시험이다.

## 지도와 리소스

방어·생존·체인: CODEX_FOREST의 세 지도. 수색: CODEX_EXPANSION의 6개 방을 모두 순차 사용. 호위: 5공중섬·선택 다리·구조 거점·귀환. 복구: 원형 섬·4채집 더미·3정화 시설. 22개 GLB는 기존 Blender 제작 소스에서 낮은 꽃/줄기/잎 장식으로 보완. 길과 충돌 판정은 authored navigation을 사용한다. 캐릭터와 펫의 형태를 다시 설계하지 않는다.
