# 수스 아케이드 — 대표 4종 3D 제작기획서 v2

## 1. 게임 컨셉과 최신 변경

루온·리아와 반려동물이 정화숲의 공중마을에서 생활하고, 비행선을 타고 오염 지역에 나가 싸운 뒤 마을을 회복하는 3D 복셀 액션 아케이드다. 따뜻한 크림·주황·민트, 자연과 기계가 공존하는 수스의 캐릭터·펫·집·숲·무기를 유지한다. 등장 모델과 배경은 현재 프로젝트에 복사된 수스 3D 자산을 사용한다.

사용자의 최신 지시로 **10개의 서로 다른 게임을 만드는 안에서 대표 플레이 4종을 중심으로 만드는 안으로 변경**한다. 기존 5구조는 의무 제작 대상에서 해제한다. 이전 10종 문서와 자산은 보관하며 삭제하지 않는다.

| 대표 프로필 | 플레이의 중심 | 수스의 적용 | 실제 규칙 계열 |
|---|---|---|---|
| p01 후더덕형 | 준비·시설 선택 → 혼합 웨이브 방어 → 강화 | 정화 코어와 시설을 지키는 전투 | base-defense |
| p02 FPS 모드 | 같은 방어전의 현장 시점·조준·위협 읽기 | p01과 같은 맵·시설·적·웨이브를 1인칭으로 플레이 | base-defense, p01에서 파생 |
| p03 탕탕·뱀서형 | 자유 이동·자동 공격·경험치·3택 성장 | 오염된 숲에서 떼를 피하고 빌드를 완성 | horde-survival |
| p04 Cell형 | 하단 좌우 이동·상향 사격·숫자 체력 대열 제거 | 오염 대열이 정화 경계를 넘기 전에 끊어내기 | chain-defense |

따라서 **등록상 대표 4종, 규칙 계열은 3개, 공통 전투 엔진은 1개**다. FPS 전용 엔진과 별도 적·무기 표를 복제하지 않는다. FPS의 초기 조작은 자동 사격·보조 조준이며, 수동 사격은 후속 선택 프로필로 보관한다. 특정 FPS 벤치마크 이름은 아직 제공되지 않았으므로 원게임을 분석했다고 주장하지 않는다.

Cell형의 근거는 사용자 영상 125.97초의 실제 프레임 분석이다. 원작의 세부 체력 공식·대열 분열 공식·전체 클리어 시간은 확인되지 않았다. 이번 수치와 판정은 수스용 제작 제안이다. [영상 분석](09_CellSurvivor_영상분석_Codex.md)에 관찰과 추론을 구분했다.

## 2. 제품과 기획툴의 관계

**기획툴에서 실행하는 화면 자체가 본 게임 수준의 실제 3D 플레이**다. 로비, 미션 카드, 대표 게임 4종을 각각 독립 실행하고, 같은 런타임으로 연결 플레이도 한다. 설정을 바꾸어 실제로 싸우고 결과를 비교한 뒤 기준 설정으로 저장할 수 있어야 한다.

별도의 간략 시뮬레이터를 본 게임 규칙과 나란히 만들지 않는다. 기획툴은 편집·검수 셸이며, 최종 제품은 같은 GameSession과 설정을 다른 셸에서 실행한다. 외형·애니메이션·타격·승패·저장이 실제 플레이로 검증되어야 완성이다.

이번에는 문서·초기 데이터와 Blender 사격 보드 준비 자산을 작성했다. 기존 `planner/data.json`, 시뮬레이터, 모델, 게임 코드는 변경하지 않았다. 기획툴의 구 10게임 메뉴는 제작 AI가 [변경 명세](10_기존10종정리_PRISM반영_Codex.md)에 따라 옮겨야 한다. 현재 메뉴가 이미 4종으로 바뀌었다고 보고하지 않는다.

## 4. 세계와 캠페인 기본 구조

공중마을 → 지역/미션 카드 → 비행선 출항 → 실제 전투 → 결과 → 카드 또는 귀환. 집 5채, 바다, 부유·폭포·새·24시간 환경, 펫 생활과 두 캐릭터의 두 비율을 유지한다. 로비 상세는 [01](01_공통런타임_로비_기획툴_Codex.md), 실제 자산은 [03](03_리소스활용_맵_아트_Codex.md)에 있다.

초기 캠페인 제안은 **지역 5개 × 카드 4개 = 20미션**이다. 한 지역의 권장 순서는 p03 상륙 정화 → p01 정화 코어 방어 → p02 같은 지역의 야간 침입/방어 시점 변형 → p04 마지막 오염 대열 차단·펫 구출이다. FPS 카드는 앞 카드의 그대로 재방송이 아니라 별도 mission override를 가질 수 있으나 첫 제작 검수는 동일 웨이브로 비교한다. 이야기 순서는 초기 제안이며 기존 s01~s10을 몰래 같은 이름의 다른 게임으로 덮어쓰지 않는다.

미션 ID는 `r01-p03`처럼 새로 발급하고, 기존 s ID와 저장은 보존한다. 구 진행도는 변환표를 보여 주고 새 캠페인으로 옮기는 선택을 제공한다. 이미 구출한 펫은 그대로 보존하며 새 클리어로 중복 지급하지 않는다. 게임 유형 수 4와 이야기 카드 수 20은 다른 값이다.

지역별 구출 펫: NoFilter → block_cat → Flux → Lumos → Gizmo. 첫 지역은 동행 펫 없이도 모든 프로필을 클리어할 수 있다. 구출 후 1마리 동행 선택. 시설만 모드는 인간 모델을 숨기는 정식 p01 변형으로 유지하며 자동 성공하는 관전 모드가 아니다.

영구 저장: 카드 개방·최고 성적·펫 구출·선택 캐릭터/비율/동행·로비 설정. 판 안 성장: 무기·패시브·시설·강화 카드. 판 안 성장은 다음 미션에서 초기화한다. 영구 전투 능력 구매·과금·PvP는 첫 제작 범위에 넣지 않는다.

5지역 배율은 기본 표 위에 적용한다. HP `[1,1.15,1.3,1.45,1.6]`, 접촉 피해 `[1,1.08,1.16,1.24,1.32]`, 이동 속도 `[1,1.03,1.06,1.10,1.15]`. 보스 절대 HP와 p04 대열 숫자 예산은 전용 표의 배율을 한 번만 적용한다. 준비·메뉴를 제외한 한 지역 약 18~25분은 목표이며 실제 플레이로 검증해야 한다.

## 6. 다른 AI의 첫 제작 범위

M0: 자산/표 검증·고정 틱·동일 세션·입력·로딩·소켓·로그의 초기 구조. M1: p01 한 게임을 준비/시설/3전투/보스/성공·실패까지 실제 조작으로 완성. M2: 공중마을·카드·출항·귀환 연결. 그 뒤 같은 엔진으로 p03, p02, p04를 확장한다.

빈 스텁이 성공을 반환하거나 뷰어에서 모델이 보이는 것을 게임 완성으로 기록하지 않는다. 완료 보고에는 정상/실패/재도전 로그, 사용 설정 해시, 실제 플레이 스크린샷, 남은 작업을 함께 제출한다.
