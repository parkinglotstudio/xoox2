## 3. 공통 전투와 성장
BaseDefense에 실제 피해/투사체/범위판정/상태/경험치/카드/확장기술의 공통 실행이 있다. HordeSurvival은 일정·생존 목표·드롭을 추가하고, AdventureRules는 HordeSurvival을 상속해 목표만 바꾼다. ChainDefense는 체인 이동/관통/전용 보급을 유지한다. 고정60틱, 얼린 설정 사본, 설정 해시, 난수 시드, 명령 기록은 그대로 사용한다.

성장 표는 common.json / rulesets.json / skills.json. 무기20슬롯·패시브7종·최대100레벨. 시작3선택, 전투6초마다 추가 선택, 기본 XP4와 레벨당1.5 증가, 일반/정예/보스 XP3/10/50, 흡인16m·회수1.8m. 새 기술·기존 강화·패시브 선택지를 구별해 제공하고 진화 조건이 맞으면 먼저 보여준다. 기존 대생존의 확장기술도 코어 방어에서 같은 공통 코드로 작동한다. 체인·시설 전용은 전용 보급을 제공한다.

기획툴 오른쪽 기술·진화 시험은 부모창에서 arcade:showcase 메시지를 보낸다. GameApp은 부모와 origin을 검사하고 plannerTest에서만 적용한다. 선택한 효과 시험 중 일반 성장 선택을 잠시 멈추며, 다시 실행하면 일반 성장으로 돌아간다. 모든 일반 기술 동시 적용과 진화4종 개별 시험 가능. 캠페인 저장에서 제외된다. 선택한 진화는 정식 무기Lv5·짝 패시브·진화 적용 경로를 사용한다.

## 4. p05 방 돌파
AdventureWorld가 forest_rooms의 layout6개와 변환GLB6개를 읽는다. 빈 방→암석→기둥→웅덩이→가시→보스. 플레이 영역12×18m, 실제 장애물 사각형과 문 좌표를 사용한다. 적이 남아 있으면 문이 닫히고, 실제 처치 후 정화된 맵으로 바뀐다. 북쪽 출구(x±1.5,z<-7.7)에 도착해야 다음 방으로 간다. 마지막 보스 처치와 출구 도착이 승리 조건이다. 마지막 방의 구출 펫도 표시한다.

가시·웅덩이는 빨간 사각 예고와 활성 단계로 구분한다. 활성 때 실제 피해, 웅덩이는 이동 감속. 다음 방 전환 시 투사체/드롭/영역을 정리하고, 비동기 맵 변경은 epoch 검사로 이전 방이 다시 나타나지 않게 한다. 사람HP0·제한시간240초는 실패. 방 통과 보급도 성장 선택을 준다.

## 5. p06 호위·탈출
기존 sky_route의 섬5개와 다리5개를 사용한다. 시작섬→체크포인트→갈림섬→종점섬, 넓은 우회는 작은섬을 거친다. 종점에서 동물을 수레에 싣고 갈림섬 탈출 거점으로 돌아온다. 경로 버튼은 갈림길 진행 전 변경 가능하다. 거리5.5m 안의 캐릭터와 주변 적 저지 여부가 수레 이동을 결정한다. 수레HP480, 속도3.2m/s, 도착 보급/수리. 실제 펫이 구출 후 수레 위에 나타난다.

내비는 섬 타원+다리 폭의 합집합으로 바다 이동을 막고 다리 높이를 보간한다. 바닥 높이는 시작0m·체크포인트1.2m·갈림2m·우회2.6m·종점3m. 사람·적·펫·수레·투사체·범위 표시·카메라에 높이를 반영했다. 수레는 공통 적 피해의 dashVictims/targetById에 포함되므로 근접·직선탄·범위 공격 모두 적용된다. 사람HP0·수레HP0·시간초과 실패. 도착 조건 없이 자동 성공하지 않는다.

## 6. p07 정화 복구
상륙섬 landing을 재사용한다. 중앙34×34m의2m 정화 셀324개를 이동 반경2.3m로 칠한다. 정화45%+시설3곳 복구가 모두 필요하다. 시설은 작업3초와 정화석2개, 채집 더미4곳은 각각2개를 제공한다. E 또는 작업 버튼을 누르는 동안 가까운 채집/복구 작업이 진행되고 작업 퍼센트를 표시한다. 복구 후 기존 tower_crystal 복셀 시설이 나타난다. 제한360초·사람HP0 실패. 자원 무한 생성과 무제한 복셀 월드 엔진은 없다.

## 7. 마을 침략과 펫
LobbyRaid.ts가 기존 VILLAGE03 로비에 추가됐다. 최초180초 후 접근, 이후300초 간격. 경고6초→침략→결과·복구9초→평온. 3종 공중 몬스터24개가 여러 방향으로 날아온다. 기존 수정 포탑3개가 실제 투사체로 공격하고 구조한 펫들이 지원한다. 정화 집중 버튼은 범위 피해와 방어 수리를 제공한다. 코어HP0·90초 초과 실패, 모두 처치하면 승리. 영구 집 손실이나 오프라인 피해는 없다. 숨겨진 로비와 외출 중 시간은 누적하지 않는다. 결과는 시험과 일반 로비를 구별해 저장한다.

외출 펫 역할은 common.pet.roles 표: NoFilter 회복, Flux 빠른 화염, Lumos 감속, Gizmo 수레 정비, Pixel 경험치 지원. 기존 애니메이션과 모델을 유지했다. 마을 침략의 구출펫 수와 지원 공격력은 lobby.invasion 표에서 향후 균형을 조절한다.
