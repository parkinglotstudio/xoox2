# 스킬 성장과 전투 연출 제작 계약

작성: Codex · 2026-10-11 · 대표 4종 v2

이 문서의 수치는 수스의 3~5분 미션에 맞춘 초기 설정이다. PRISM의 실제 값과 구분한다. 설정 정본은 `data/skills.v2.json`, `data/presentation.v2.json`, `data/prism-adaptation.v2.json`이다. 카드 이미지·무기 모양·펫·배우는 기존 수스 자산을 사용한다.

## 2. 슬롯과 공격 주기

기본 무기 1개는 액티브 슬롯을 소비하지 않는다. p01/p02/p03의 액티브 슬롯은 3개, 패시브 소유 종류는 4개다. p04는 기본 사격의 탄수/연발/공속/피해/관통을 독립 랭크로 올리고 보조 스킬 2개만 사용한다. p04에서 이속·인간 HP·일반 진화 후보를 섞지 않는다.

기본 속사는 `FIRING(3s) → REST(2s) → FIRING`으로 반복한다. 16발/초는 두 손 합계이며 왼쪽/오른쪽 소켓을 교대한다. 타깃이 없으면 발사 주기를 정지하고 발사 재개 시 즉시 1발을 낸다. REST는 타깃 유무와 관계없이 게임 시간으로 진행한다. 카메라 교체는 이 상태를 초기화하지 않는다.

연발은 한 묶음의 발사 간격과 묶음 사이 쿨을 분리한다. p04의 이론 DPS는 `피해*탄수*연발수/(묶음쿨+(연발수-1)*연발간격)`이다. 관통은 탄 개수가 아니므로 DPS에 무조건 곱하지 않고 실제 명중 대상 수를 기록한다. 각 탄은 `hitEntityIds`를 갖는다.

공전·장판·오라는 지속 상태다. 쿨 0 공전은 매 틱 새로 생성하지 않는다. 생명주기 1개를 유지하고 접촉 대상별 다음 타격 틱을 예약한다. 드론은 외형 2개와 피해 발사 주기를 분리하며 배우 카메라에 고정된 장식처럼 만들지 않는다. 모든 패턴이 일시정지/재시작/dispose를 지원한다.

## 3. 성장과 선택 알고리즘

1. XP는 유효 처치 이벤트에서만 생성한다. 충돌/사망 큐로 중복 생성하지 않는다. 일반 1, 엘리트 4, 보스 20이다.
2. XP 구슬은 개별 DOM 대신 인스턴스 풀로 배치한다. 평상시 끌림 반경 2m, 회수 반경 .35m, 최대 동시 160. 초과분은 근처 같은 값 구슬로 합치며 총 XP를 보존한다. 자석은 5초·12m 반경이다.
3. 레벨업마다 필요 XP를 차감해 초과분을 보존하고 `pendingLevelUps`를 만든다. 한 번에 여러 레벨이 오르면 선택 화면을 순서대로 연다. Lv16 이후에는 공격 성장 대신 회복/결과 조각을 지급한다.
4. 현재 구현 완료·슬롯 가능·레벨 미완료·프로필 허용 후보만 만든다. 후보 ID를 중복 제거한 뒤 seed RNG로 가중 비복원 추출한다.
5. 기본 후보 가중치 1, 소유 장비 강화 2, 소유 장비의 없는 진화 짝 1.5다. 유효 진화가 있으면 최대 1장을 첫 칸에 놓고 나머지 2장을 뽑는다.
6. 후보가 3개 미만이면 `heal20`, `result-fragment`를 사용한다. HP가 가득 차면 heal20은 제외한다. 선택 불가능한 빈 카드/이미 최대 레벨 카드는 금지다.
7. 선택 직후 상태 변경을 한 트랜잭션으로 반영하고 250ms 확인 연출 후 100ms 입력 차단을 거쳐 재개한다. 패시브를 바꾼 뒤 이미 진행 중인 발사/장판의 예약 시간을 소급 변경하지 않는다.

카드는 이름·현재/다음 레벨·신규/강화/진화 배지·기능 설명·변화량을 보여 준다. 공속+20%와 쿨-20%는 다르다. p04 카드에는 결과 탄수/연발수/기본 DPS를 함께 표시한다. 키보드1/2/3, 패드/터치, 선택 취소 없는 일시정지 메뉴를 지원한다.

|---|---|---|

| bomb + hp | carpet-three | 다른 지점3개에 폭탄, 각 원래 피해×.6, 폭발당 대상1회 |

진화는 기존 액티브 슬롯을 교체하며 패시브를 소비하지 않는다. 교체 결과는 별도 Lv1 고정으로 보관하고 기존 Lv5 피해 배율을 다시 곱하지 않는다. 결과 피해는 `inheritsSkillId`의 **Lv5 결과값**에 명시된 계수를 적용한다. 공전 결과는 명시 피해12가 기준이고 기존 로켓 피해를 사용하지 않는다. 지역/공통 패시브 계수는 이 처리 이후 1회 적용한다.

PRISM의 8진화는 비교 표본이다. 수스 초기 진화는 위 4개이며 나머지 패턴 진화/드론 합성은 후속이다. 무기Lv5+짝이 있으면 다음 엘리트 상자에서 우선 제시하고, p03 150~270초에는 레벨업에서도 허용한다. 조건 불충족인 진화 카드는 숨긴다.

## 4. 원소와 피해 원장

불: 3초, .5초마다 2피해. 동일 시전자/스킬 재적용은 지속시간 갱신, 피해 스택을 늘리지 않는다. 얼음: 2초·속도 .65배, 가장 강한 감속만 적용. 번개: 동일 연쇄의 재방문 금지. 적 독은 스택 최대5·각스택4초·.5초 틱이며 총피해값은 적 표에서 정한다. 틱이 끝나기 전에 사망하면 후속 예약을 취소한다.

`DamageEvent`는 ownerId, sourceCategory(character/skill/facility/pet), skillId, projectileId, targetId, rawDamage, appliedHpDamage, absorbedDamage, killed, tick를 갖는다. 결과 피해량은 `appliedHpDamage=min(남은HP, 방어후피해)`만 합산한다. 같은 피해를 캐릭터와 스킬 두 항목에 동시에 넣지 않는다. 지속 피해는 원래 시전자 출처를 유지한다. 소환 UFO는 스킬 피해이며 동행 펫 피해와 구분한다.

진화·치명타·면역·범위 피해는 원장으로 추적한다. 죽은 대상/보호 대상의 0피해는 발사 로그에는 남아도 결과 피해량에는 더하지 않는다. 결과 화면에서 캐릭터/스킬/시설/펫 기여도를 표시하고 활성 적·명중률·누출·카드 선택을 기획툴에서 펼쳐 본다.

## 5. 전투 연출과 소리

| 상황 | 기본 연출 | 시간·상한·예외 |
|---|---|---|
| 쌍권총 | 실제 총구에서 크림/주황 블록 섬광·짧은 탄 꼬리 | 섬광60ms, 탄 피격80ms, 광원은 공유 1개·그림자 없음 |
| 로켓 | 속성별 블록탄·궤적·충돌 지점 폭발 | 범위 예고/실제 반경 일치, 후면에서도 실루엣 보임 |
| 폭탄/투석기 | 포물선과 도착 지점 링 | 착지할 때만 피해, 비행 .9초 기본 |
| 얼음 | 민트 파편과 감속 표식 | 피해 숫자와 겹치지 않게 높이 분리 |
| 번개 | 대상 사이 분절 블록 라인 | 120ms, 충돌 연쇄와 동일 대상 순서 |
| 피격 | 짧은 밝기 변화, 작은 큐브 파편 | 80ms, 얼굴을 흰 판으로 덮지 않음 |
| 사망 | 8~12 큐브 + XP 구슬 | .35~.55초, 파편 전체256 상한 |
| 건설 | 반투명 블록 윤곽·가격·확정 체크 | 부족 비용 빨간 표기, 건설 완료 .35초 |
| 스폰 | 방향 화살표와 경로 출발점 맥박 | 첫 스폰2초 전, 화면 끝과 월드 위치를 함께 표시 |
| 보스 | 경고→등장→조작 재개 | warning2초, 명시 무적1.2초, 등장 중 충돌 상태를 분리 |
| 레벨업 | 배우 주변 민트 링과 카드 | 전투는 멈춤, UI 시간만 진행 |
| 상자 | 기존 블록 상자 열림·빛·보상 패널 | 최대1.2초, skip 가능, 광고/재추첨 없음 |
| 정화/구출 | 오염색→민트 전파·펫 인사 | 게임 결과 확정 이후, skip 후 저장 결과 동일 |

피해 숫자는 월드 위치를 GPU 텍스트/아틀라스로 표시한다. 수명 .55초, 최대48, 같은 대상 같은 틱의 작은 피해는 합산한다. p04 HP 숫자96개와 피해 숫자48개는 별도 풀이다. 적 경고 영역은 VFX 저품질에서도 유지한다. 눈부신 화면 전체 플래시·매 타격 shadow point light는 사용하지 않는다.

일반 카메라 충격 최대 .08m·.12초, FPS는 위치 흔들림0·시각 반동1도 이하, 사용자가0으로 조절할 수 있다. FPS HUD의 피격 방향으로 대체한다. 원본 PRISM 보스의 큰 shake 값은 이식하지 않는다.

소리는 역할별 emit(event)로 등록한다. 동시 voice16, 같은 총소리 최소 .08초, 폭발 최소 .12초, UI선택 .05초 중복 차단. 총구 발사마다 새 AudioContext를 만들지 않는다. FPS는 방위/거리 감쇠, 탑뷰는 약한 좌우 패닝. 카드를 열면 전투 소리 루프 pause, 복귀 시 지속음 복원, dispose 시 재생 핸들을 전부 해제한다. 사용할 실제 음원이 없으면 해당 슬롯을 `missing`으로 기록하고 효과 완료라고 표시하지 않는다.

## 6. 검수와 균형 측정
