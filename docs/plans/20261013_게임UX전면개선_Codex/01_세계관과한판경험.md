# 세계관과 한 판의 경험
작성: Codex · 2026-10-13

## 이야기
공중섬 마을은 캐릭터와 구조한 반려동물이 함께 사는 안전한 집이다. 외출은 돈을 벌기 위한 메뉴 선택이 아니라 오늘의 구조·정화 시나리오를 선택하는 행위다. 귀환하면 완료 카드의 별과 구조 펫이 마을에 남는다. 전투의 목적과 결과가 이 생활 공간으로 이어져야 한다.

## 흐름
마을 → 오늘의 모험 카드 넘기기 → 카드 뒷면의 이야기·세 가지 목표 확인 → 출발 → 첫 행동 안내 → 단계별 사건/기믹 → 마지막 도전 → 성공/실패 원인과 결과 → 카드/마을 귀환.

## 한 판 기준
대부분2~3분, 수색/복구 약1~2분을 목표로 한다. 수치는 목표이며 실측 결과를 보고 조정한다. 첫20초 안에 조작과 처치를 이해하고, 30~60초에 공격 방식이 달라지는 성장, 중반의 새로운 위험, 후반의 강화·진화 또는 큰 연쇄 제거를 경험한다. 대부분의 첫 시도에서 성공할 수 있게 설계하며 실패도 어디서 어떻게 해결할지 안내한다.

## 성장 원칙
일반 플레이에서 기술 목록을 끝없이 늘리지 않는다. 6개의 공격 기술과3종 보조 안에서 기존 공격을 강화하고 진화한다. 시작1선택, 전투18초마다 보급과 XP 성장을 합쳐 10~16회 선택을 목표로 한다. 모든 기술·진화를 보는 요구는 별도의 효과 시험 기능으로 충족한다. 선택 창의 제목·신규/강화/진화·효과 그림이 서로 구별되어야 한다.

## 우선순위
P0 목표·조작·다음 행동·단계 전환·실패 원인. P1 카드 정체성·시나리오 그림·세계와 연결. P1 한 판 밸런스·각 모드 차이. P2 마을/지도 디테일·피드백·기기별 검수. 실행 오류0은 전제이며 재미와 화면 완성도의 증거로 대체하지 않는다.
