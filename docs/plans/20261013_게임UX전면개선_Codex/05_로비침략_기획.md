# 로비 침략 생활 사건
작성: Codex · 2026-10-13

## 역할
구조한 동물이 마을에서 살아간다는 보람을 짧은 공동 방어로 보여준다. 주 게임을 강제로 반복시키거나 접속하지 않은 사람을 벌주는 콘텐츠가 아니다. 기존 집5채/비행선/하늘/폭포/주민의 생활을 유지한다.

## 흐름
평온180초 누적 → 작은 접근 예고/도착 방향 →6초 준비 →공중 적3종이 여러 방향으로 접근 →방어 시설 자동 공격/펫 지원 + 사용자의 정화 집중 →성공/재정비 메시지 →평온. 실제24개체HP·명중·코어HP·시간 판정. 약45초 전투를 목표로 한다. 실패해도 집·펫 영구 손실 없음. 마을이 숨겨져 있거나 외출 중이면 시간이 흐르지 않는다.

## UI
평온은 작은 상태 배지. 접근/전투 때만 방어HP·남은 적·집중 쿨다운·조작을 확대. 무엇을 누르면 돕는지 첫 이벤트에 알려 준다. 제작실 침략 시험은 즉시 발동하고 결과를 기록한다. 구조 펫 수에 따른 지원 탄이 늘며 수치와 결과를 표시한다. 이벤트 기록은 일반 캠페인 전투 결과와 별도로 저장한다.

## 보상과 경제
현재는 방어 성공 횟수/기록과 시각 피드백만 사용한다. 새로운 재화 경제를 임의로 추가하지 않는다. 나중에 구조 펫 성장/마을 방어 효과를 연결할 때 이 계약을 확장한다.
