## 1. p01 — 정화 코어 방어 / 후더덕형

### 플레이 약속

자유 이동하는 인간과 고정 시설이 함께 정화 코어를 지킨다. 준비 중 시설을 선택하고, 전투 중 이동·자동 사격·성장 카드로 압박을 풀며, 웨이브를 끝내면 다시 준비한다. 낮밤은 환경 연출이며 필수 승패 규칙이 아니다. 전투는 사용자가 시작한다.

상태: Loading → Prep1 → Battle1 → ClearRemaining → Prep2 → Battle2 → ClearRemaining → Prep3 → Battle3+Boss → Win/Lose. 전투 시간만 battleSec에 누적한다. 살아 있는 적을 남기고 예약 시간이 끝났다는 이유로 준비 단계로 넘어가지 않는다.

### 시설 역할과 애니메이션

| 시설 | 가격 | Lv1 공격 | 대상/기능 | 동작 |
|---|---:|---|---|---|
| 화염 범위포 |70|24피해/3초, 반경2.2m, 사거리13m|지상 범위, 3초 불 지속|조준→느린 장전→발사→착지 폭발 |

시설 업그레이드: 화염/얼음60→90, 번개70→100, 방벽40→70. 공격 시설 피해1/1.35/1.8, 쿨1/0.9/0.8, HP1/1.3/1.6. 방벽 HP는240/330/440. 판매는 실제 누적 사용비용의70% 내림, 코어 판매 불가, 전투 중 건설/판매/업그레이드는 불가. 이동 입력은 건설 메뉴를 닫은 뒤 활성화한다.

투석기 외형 변형을 사용하면 팔 준비0.3초→release→0.75초 비행→지점 폭발→회복0.6초. 직접탄처럼 적 몸에 붙여 즉시 피해를 주지 않는다. 일반 속사·관통은 빠른 직접 공격, 범위포·폭탄은 느린 공격으로 구분한다.

궁극기: 3충전, 선택한 서로 다른3지점에 각60피해/반경3.2m. 월드 누르기→예고3원→확인 버튼. 취소하면 소모하지 않는다. 코어/인간은 피해를 받지 않고 자동 발동 기본 꺼짐. 시설만 모드에서는 같은 궁극기가 직접 조작이다.

### 편성과 경로

웨이브1: green_blob12+pink_slime12. 웨이브2: green_blob16+cactoro16+orc_enemy16. 웨이브3: pink_slime24+green_spiky_blob24+wizard24, 마지막 goleling_evolved 보스1. 세 종류는 각기 다른 경로와 시작 오프셋0/0.8/1.6초를 사용한다. 일반 스폰은 약38초 안에 끝나도록 그룹별 간격을 계산한다. 그룹 전부를 순서대로 방출하지 않는다.

일반 HP는 공통 카탈로그에서 가져오며 보스는 절대900이다. `bossHpAbsolute`에 종 기본HP×지역배율을 다시 곱하지 않는다. 초기 전투는 적의 약한 종이 눈에 띄게 빨리 죽고, 탱크/정예만 역할을 유지해야 한다. 실제 처치시간과 잔여 적 수를 로그로 비교한다.

경로3개, 횡방향3차선, 속도·개체 반경은 종별. 인간/시설 둘레 접근 슬롯을 배정한다. 일반 최소 중심거리=max(설정 간격, 두 반경의 합×1.05). 길이 좁으면 재경로/접근 슬롯 교체, 바다로 밀어서 제거하지 않는다. 공격 범위에 들어온 적은 자기 위치에서 예고 후 공격한다.

### 성장과 변형

처치 XP1/정예4/보스20, 첫 레벨 필요8, 이후 +4. 유효3택, 총 자동 사격의 피해/공속·바주카/패시브 선택. 첫 전투에서 최소2회의 의미 있는 강화가 나오는지 실제 처치·회수율로 확인한다. 시설 강화를 인간 무기 슬롯에 잘못 넣지 않는다.

`facilityOnly`: 인간과 영웅 XP 제거, 시작 포인트240, 코어 피해×1.4, 스폰간격×1.15. 준비 중 시설3택 보급을 제공하고 카드 선택 정책은 시설용 풀을 사용한다. 적이 코어/방벽/시설을 실제 공격한다. 임의 시간 생존만으로 클리어하지 않는다.

`laneDefense`는 후속 변형: 구 g07 길2/비행길1/건설8칸/막사·대공·누출 규칙을 같은 표 체계로 옮긴다. p01 기본판과 섞어 동시에 코어HP/누출내구를 적용하지 않는다. 첫 대표4종 완성 전에 길목 변형8웨이브를 필수로 넣지 않는다.

### 전용 검수

준비 클릭이 인간 이동으로 전달되지 않음; 코어HP/경제 양수; 느린 범위탄은 착지 때 피해; 2~3종 동시/분산; 전투 종료와 잔여 적 정산; 시설만 모드의 실제 실패; 보스 카메라·예고; 판매 환급 중복 방지.

## 2. p02 — 정화 코어 방어 / FPS 모드

### p01과 같은 것

rulesetId=`base-defense`. 맵·코어·시설·적·웨이브·HP·피해·경제·성장·승패를 p01에서 그대로 상속한다. 복제된 p02 무기표/웨이브표를 만들지 않는다. 프로필에는 firstPerson 시점, 입력/조준 정책, FPS HUD만 추가한다.

첫 검수는 p01과 같은 mission variant·seed·월드 입력으로 수행한다. 카메라만 교체한 리플레이의 스폰/HP/결과는 동일해야 한다. 실제 FPS 사용자는 시야와 조준이 달라져 명중률·클리어 난이도가 달라질 수 있으므로 카메라 전환 검수와 사람 난이도 검수를 분리한다.

### 조작과 시점 초기값

| 항목 | 초기 제안 |
|---|---|
| 이동 | 왼쪽 조이스틱, 시선 yaw 기준 평면 이동, 속도4.5. 수직 이동/점프 없음 |
| 시선 | 오른쪽 빈 영역 드래그. 1CSSpx당0.18°, pitch -35°~45°, 데드존2px |
| 사격 | 기본 자동. 전방 원뿔 반각18°+가시선 안 표적에 보조조준. 수동 버튼은 후속 옵션 |
| 조준 보조 | 현재 표적0.2초 유지, 최대 회전 보정90°/초. 벽 뒤/시선 밖 자동 명중 금지 |
| 시야 | 수직FOV60°, near0.05m, 인간 기준 눈높이1.20m. 비율별 카메라 위치 검수 |
| 흔들림 | 머리 흔들림 기본 꺼짐. 반동 시각1° 이내, 판정 방향을 무작위로 흔들지 않음 |
| UI | 조준점·HP·코어HP·웨이브·무기·현재 강화. 뒤쪽 위협 방향 원호·소리·코어 경고 |

시설 메뉴/카드가 열리면 시선·사격·전투틱 모두 정지. 메뉴를 닫은 손가락이 즉시 총을 돌리지 않도록 포인터 해제까지 소비한다. 모바일의 이동과 시선은 별도 pointerId를 소유한다. PC는 WASD+마우스 시선, Escape로 일시정지·포인터 잠금 해제.

### 총구·엄폐·몸체

조준점에서 카메라 ray로 목표점을 얻고, 실제 muzzle→목표점 선분의 첫 충돌을 사용한다. 카메라에서는 적이 보여도 총구 앞 벽에 막히면 벽 명중이다. 화면용 팔/총 view model은 시각용이며 탄 생성 위치는 월드 소켓이다. 손/무기가 near-plane에 잘리거나 벽을 뚫고 보이면 view model 카메라·깊이 정책을 조정한다.

기존 전신 모델은 그림자/외부 뷰용으로 유지하고 자신의 얼굴·머리 내부 표면만 FPS 카메라 layer에서 숨긴다. 루온/리아의 팔·옷·쌍권총·바주카를 기존 메시/리그에서 파생해 보존한다. 커다란 머리를 카메라 바로 앞에 둬 화면을 가리게 하지 않는다. FPS 팔용 애니메이션은 아직 없는 추가 표현 작업이다.

쌍권총 자동 루프와 큰 총 발도/납도를 상태기로 연결한다. 시설·펫은 같은 월드에서 공격한다. 펫이 시야 앞을 계속 가리면 뒤/옆 추종 슬롯으로 배정하되 피격/공격 판정은 사라지지 않는다.

FPS에서 벽·풀·기계의 높이를 실제 충돌과 시야에 반영한다. 탑다운에서 단순 장식이던 바위가 총구를 완전히 막는다면 이동 가능 사격 지점/엄폐 상한을 검수한다. 시야 밖 적도 정상 AI/스폰을 유지하며 렌더 culling으로 전투를 없애지 않는다.

### 전용 검수

카메라 교체 리플레이 동일성; 이동+시선 멀티터치; 표적 시야 이탈·벽 가림; 카메라 ray와 muzzle 충돌 불일치; 쌍권총 양손/바주카 크기·소켓; 코어 후방 경고; 카드 닫기 오발; 회전/카메라 흔들림 감소; 무기 모델 저프레임에서도 같은 발사 수.

## 3. p03 — 떼 생존 / 탕탕·뱀서형

### 플레이 약속

이동에 집중하면서 적 떼를 피하고 XP를 주워 3택 성장으로 무기를 조합한다. 공통 무기·카드·적을 사용하지만 시설 비용/건설칸/코어 목표는 없다. 강해진 빌드가 투사체 수·관통·연쇄·장판 변화로 직접 보인다.

상태: Loading → Intro → Survival0~300 → FinalBoss → Win/Lose. 300초에 일반 스폰을 끝내고 마지막 보스를 만든다. 중간 보스는150초, 첫 등장 예고2초. 중간/마지막 보스 전후5초 급습 스폰 금지. 살아 있는 일반 적은 사라지지 않지만 동시 상한을 유지한다.

스폰 기본:0~10초0.3체/s,10~30초0.8,30~90초1.8,90~150초2.8,150~240초3.4,240~300초4.2. 이 수에 급습·편대도 포함하며 ‘기본 수+추가 수’로 무제한 더하지 않는다. 기본 역할 비율은 약한 떼70%/돌진20%/탱크10%, 후반 원거리·비행 대체는 같은 예산을 빼서 편성한다.

첫10초의3체는 스폰 구역을 화면 밖 안전거리로 선택한다. 일반 스폰은 인간에서8~13m, 실제 보행면과 가시성 정책 확인. 갑자기 인간 위치에 적을 생성하지 않는다. 무적이 끝나는0.6초가 위험 예고를 대신하지 않으며, 빠른 돌진은 별도0.6초 선 예고를 한다.

급습은60/120/210/270초, 예고2초, 12체의 열린 부채형 접근으로 빈 회피 방향을 남긴다. 편대는90/180/240초에6체, 2~3행·종류별 경로와 속도. 머리부터 꼬리까지 한 줄로 모든 자유 적을 묶지 않는다. 소환 구역·편대 경로가 플레이어를 완전히 봉쇄하면 해당 편성은 무효다.

강화는 무기3슬롯+패시브4종, 기본 쌍권총 별도. 7바주카 외형과 발사 방식으로 spread/homing/parabola/orbit/chain의 빌드를 만든다. 처음부터 PRISM25종 전부를 새 외형으로 만들지 않는다. 첫판 진화가 가능한 경험치·짝 후보를 제공하고 Lv5 무기+짝 패시브Lv1이면 진화 최대1장 우선 제공. 150초 이후 레벨업 풀에도 진화를 허용해 상자가 없어서 막히는 경우를 없앤다.

회복/자석은 실제 충돌/수집 이벤트. 화면 클릭 하나로 모든 XP를 자동 얻는 것을 기본 규칙으로 쓰지 않는다. 자석 지속5초 반경12m, 레벨업 선택 중 남은 지속시간도 멈춘다.

## 4. p04 — 오염 대열 차단 / Cell형

### 플레이 약속과 다른 규칙

수스 캐릭터가 하단 정화 경계에서 좌우로 움직이며 위로 사격한다. 숫자 체력이 붙은 대열이 굽이쳐 내려오고, 마디/머리/보상 표적을 제거해 화력으로 길을 연다. 다른 세 프로필의 자유 추적 AI를 그대로 적용하지 않는다.

상태: Loading → OpeningChoice → Formation1 → Choice → Formation2 … Formation6 → Win/Lose. 한 편대의 모든 살아 있는 마디·머리·보상 표적이 정산된 뒤 다음 편대를 시작한다. 영상의 무한/장기 구조를 확정할 수 없어 첫 수스판은 유한6편대로 검증한다.

p04는 경계 실패를 사용하므로 공통 인간HP는 이 프로필의 승패에 쓰지 않는다. 화면에 무의미한 인간HP를 표시하지 않는다. 머리가 자기 앞의 마디보다 특별히 경계를 넘으면 실패하는 것이 아니라 **살아 있는 대열 구성원 하나라도 경계를 접촉하면 실패**다. 이것은 수스 제안 규칙이며 원작 내부 조건을 단정하지 않는다.

### 대열 좌표·제거·충돌

편대는 polyline의 누적 호길이 s를 사용한다. 머리의 s는 `speed×activeSec`, 마디 i는 `headS - orderIndex×spacing`이다. 시작점 이전의 마디는 비활성 대기하고 충돌/라벨/공격이 없다. 한 마디가 제거되어도 남은 orderIndex를 다시 매기지 않아 순간 압축·순간이동이 없다. 사라진 공간은 빈틈으로 남고 새 머리를 만들지 않는다. 추후 splitChains 변형은 별도 설정/검수 후 추가한다.

좌우 왕복 경로는 모서리 부근에서 아래쪽으로1.5~2m 꺾인다. 경로는 C1 둥근 코너 또는 제한된 회전속도로 렌더하고, 거리 계산은 실제 경로 호길이로 한다. 경로 끝은 경계를 통과한다. 머리만 죽어도 남은 마디는 기존 경로/속도로 계속 이동하며 전부 제거해야 편대가 끝난다.

표적은 `{formationId, segmentId, orderIndex, hp, role, pathS}`다. 머리/일반/장갑/보상 표적 모두 별도 충돌과HP를 가진다. 장갑은 숫자HP로 표현하고 추가 숨은 방어×0.15를 겹치지 않는다. 숫자는 현재HP 올림 정수, 직접탄은 가장 앞의 실제 충돌부터, 관통은 충돌거리순으로 서로 다른 segmentId에만 적용한다. 폭발은 같은 마디1회, 연쇄는 같은 chain의 다른 마디도 서로 다른 대상이다.

두 경로가 교차하면 월드 collider로 충돌 순서를 구하고 라벨의 화면 위치로 판정하지 않는다. 자유 적의 분산/접근 AI는 `pathPolicy=chain`에 적용하지 않는다. 대열은 의도된 편대이고 모든 몬스터를 한 점에 몰아넣는 규칙과 구분한다.

### 성장·공격 방식

처음3택은 탄수+2 / 공속+20% / 피해+30%로 모두 유효한 선택. 카드마다 다른 효과를 파라미터로 제공하고 첫 선택 후 기본 무기의 시각이 즉시 바뀐다. 편대1~5 끝마다3택1회. 전체 판 마디 처치30/70/120/170에서 추가3택, 같은 틱 복수조건은 큐에1개씩. 선택 중 대열·탄·경계시간·지속효과 모두 정지한다.

탄수 count는 한 연발에 동시에 나오는 병렬탄 수, 최대5. 연발 burstCount는 그 묶음을 짧은 간격으로 다시 쏘는 수, 최대3, 간격0.06초. 쿨은 마지막 연발 이후 다음 연발 묶음까지, 0.25초×쿨계수, 최저계수0.6. 공속 카드의 표기는 실제 묶음 주기에 환산해 표시한다.

이론DPS=`피해×탄수×연발수 / (쿨 + (연발수-1)×연발간격)`이다. 기본 40DPS, 한 선택으로 탄수가3이면120DPS. 원작 HP수천을 그대로 가져와 화력이 부족해지는 오류를 막고, 실제 적렬에 맞는 탄수·명중률·관통을 로그로 본다. 병렬탄이 모두 같은 마디에 맞는지 아니면 옆으로 흘리는지에 따라 실효DPS가 크게 달라진다.

보조 후보: 번개 관통탄16피해/1.2초/관통3, 폭탄40피해/4초/반경2.4m, 얼음 회전/연쇄는 후속스킬. 관통 +1은 최대5대상, 여러 마디가 같은 틱 겹쳐도 충돌거리순 중복 없이 처리. 탄수/연발/피해/쿨/관통의 무제한 곱셈은 허용하지 않는다. 카드 풀과 레벨 상한은 skills.v2에서 관리한다.

머리를 때렸다는 이유로 몸 전체HP를 동시에 깎지 않는다. 장판은 대상당0.5초 간격, 여러 마디를 각자의 collider로 검사한다. 폭발지점은 경로의 예상 위치가 아니라 실제 충돌/선택한 착지점이다.

보상 별은 `rewardMembersKilledBeforeHeadFraction`이다. 편대의 머리 사망 틱보다 앞선 보상 마디 처치 틱을 센다. 같은 틱이면 실패 우선과 별도로 보상 선처치에는 포함하지 않는다. 최종적으로 모든 마디를 처치해도 이 선처치 비율은100%가 아닐 수 있다.

진행률은 `파괴한 초기HP예산 / 전체6편대 초기HP예산`, 최대100%. HP 수치가 큰 끝 편대의 영향을 반영한다. 피해를 준 양이 아니라 제거된 표적의 최초 예산을 더하고, 회복/중복사망으로 증가하지 않는다. 보스 클리어 전에100%가 되는 오류를 방지한다.

### 실패·재도전·연출

경계2m 전 노랑,1m 전 빨강과 소리. 화면 흔들림 감소 옵션에서 경고 자체는 남긴다. 실패 즉시 입력/공격/대열을 정지, 닿은 segmentId와 위치를 기록한다. 결과는 ‘오염 대열이 정화선을 넘었습니다’로 설명한다. 광고 부활을 가져오지 않고 같은seed 재도전/로비를 제공한다. 개발용 이어하기는 testOnly이며 캠페인/별 지급 금지.

3D 숫자는 배치형 글리프 또는 제한된 pooled sprite-text로 최대96개. 숫자 표현은 UI이며 캐릭터를2D로 바꾸는 의미가 아니다. 가려진 숫자는 우선순위/축소를 쓰고 DOM96개를 매프레임 각각 배치하지 않는다. 개별 숫자 충돌을 해결해HP를 읽을 수 있어야 한다.
