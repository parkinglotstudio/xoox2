# 전체 완성 실행 계획 — Codex

작성: Codex · 2026-10-11

사용자 승인: 대표4종, 로비, 카드 미션을 기획툴에서 각각 실제 실행하고 설정/플레이/결과를 확인할 수 있게 완성. 소리 및 배포 빌드는 제외.

1. 기존 src/arcade와 config를 보존하고 src/arcadeComplete 및 config-codex에 확장. 원본 3D 모델과 캐릭터 디자인 유지.
2. 공유 전투/입력/저장 결함 수정. FPS는 p01 전투를 상속하고 시점/입력만 변경.
3. 대생존의 실제 스폰/성장/보스와 체인의 이동/HP/관통/경계 실패/6대열 구현.
4. Blender로 기존 모델 렌더링 → 모든 미션/성장/시설 카드 실제 그림 생성.
5. 튜토리얼, 펫 선택/이동/실제 피해, 시설 동작, 모바일 HUD 및 전투 연출.
6. 기획툴 실행 패널/수치 편집/시험 기록/별도 캠페인 저장 연결.
7. 실제 브라우저로 4종 승패/재시작/카드/미션 잠금/펫/설정 반영, 캡처와 보고. 모바일 기기 성능과 사람의 장기 플레이 평가는 측정 범위를 명시.
