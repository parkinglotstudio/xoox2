# 수스 캐릭터·유닛 제작 인계
작성: Codex · 2026-09-27

이 대화에서 진행한 **캐릭터 제작, 유닛 리소스 실험, 애니메이션, FX, 비교 툴**의 통합 문서다. 현재 사용본과 과거 실험을 구분하며, 과거 보고서는 작성 당시의 기록으로 보존한다. 다른 작업자가 별도로 만든 맵·본편 시스템의 완료를 이 문서에서 주장하지 않는다.

## 다른 AI에게 인계하기

[원본 캐릭터·유닛 AI 인계 프롬프트](../handoff/20260927_캐릭터유닛_Codex/PROMPT.md)를 전달한다. 툴 종류별 주소·소스·제작 방법·검증 순서가 한 문서에 있다. 이후 작업 기준은 C:\xoox이며 별도 복사본 작업과 그룩 체크는 종료했다.

## 읽는 순서

1. **[캐릭터를 만든 방법](01_캐릭터_제작방법.md)** — 그림 측정부터 블록 형상, 얼굴, 스킨, 동작, 무기, GLB, 3.5등신까지.
2. **[전체 작업 이력·근거](02_전체작업이력.md)** — 점구름부터 현재 이름 체계까지. 관련 보고서 전수 색인.
3. **[실행·검증·복구](03_실행_검증_복구.md)** — 정확한 실행 경로, 재제작 순서, 알려진 한계와 인계 규칙.
4. **[파일 목록](04_파일목록.md)** / [기계 판독 목록](inventory.json) — 소스·모델·참고 그림·라이선스·보고서 경로와 SHA256.

## 현재 선택지는 네 가지

| 이름 | 성별 | 체형 | 툴 ID |
|---|---|---|---|
| 루온 | 남자 | 기존 비율 | RUON |
| 루온 | 남자 | 3.5등신 | RUON_35 |
| 리아 | 여자 | 기존 비율 | RIA |
| 리아 | 여자 | 3.5등신 | RIA_35 |

- 루온은 2026-09-26 새로 제작한 A 계열이다. 예전 루트 폴더의 `wanderer_A.glb`와 다른 자산이다.
- 리아는 D08 계열이다. 예전 B/B2/C와 구분한다.
- 사람 캐릭터는 모두 18개 동작. 블록 고양이 BCAT02는 별도 펫이며 6클립이다.
- 약 4.4등신 DS 및 과거 시안은 활성 선택에서 제외하고 백업했다.
- 이번 마무리에서는 루온 두 체형의 정수리만 보정했다. 얼굴·몸·의상·무기 및 애니메이션 키 보존 검사를 수행했다.

## 운영 원칙

작업 루트는 `C:\xoox`. 그룩봇 지시·작업 목록 확인은 사용자가 중지했다. 이후 변경은 채팅의 직접 지시에 따른다. 작업 계획·완료 보고와 스크린샷을 남기고, 상태판 자기 행만 수정한다. 다른 작업자의 코드·기록을 보존하며 커밋·푸시는 별도 사용자 요청이 있을 때 한다.

모델링에는 로컬 Blender Python과 TypeScript 툴을 사용한다. 이 제작·재생 경로에 외부 AI API 키는 필요하지 않다.
