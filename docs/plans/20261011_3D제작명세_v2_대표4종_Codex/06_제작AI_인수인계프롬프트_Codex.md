먼저 `docs/plans/20261011_3D제작명세_v2_대표4종_Codex/00_제작기획서_Codex.md`와 01~13, data/초기표·validation·리소스 목록을 읽어라. 기존 기획 정본 `planner/data.json`, Claude의 `docs/plans/20261011_PRISM구조분석_Claude.md`도 확인한다. 이전5구조/10독립게임 제작안은 보관 참조이며 최신 범위가 아니다.

최신 대표는 **p01 후더덕형, p02 같은 방어전의 FPS 모드, p03 탕탕/뱀서형, p04 Cell형**이다. 규칙 계열3개와 공통 전투엔진1개를 사용한다. 무기·탄·피해·속성·적·카드·스폰·결과는 공통표/서비스, 카메라/입력/이동/목표/편대는 정책으로 분리하라. FPS 전용 웨이브/피해코드를 복제하지 말고 p01을 상속한다. Cell형의 연결경로/개별마디HP/경계실패는 신규정책이다.

제품은 수스 정화숲 세계의 루온/리아·반려동물·공중마을이다. 3D공중마을 로비, 미션 카드, 대표4종, 결과/정화/구출/귀환을 기획툴에서 각각 독립실행·편집·플레이·기록하고 연결플레이도 한다. 같은 GameSession/config를 나중에 최종 게임 셸에서 실행한다. 간략2D시뮬레이터·임의성공스텁을 제작완료라고 말하지 마라.

기존두캐릭터/두비율·펫5종·복셀몬스터45+UFO4·무기/FX·시설·캠프·기계·숲·Claude맵24GLB·VILLAGE03을 최대한 재사용한다. 기존 얼굴/머리/옷/펫 디자인을 임의로 다시 만들지 않는다. CHAIN01은 새 사격 보드 준비 자산이며 런타임 구현은 남아 있다. 11문서의 슬롯·패턴·진화·원장·FX·오디오와 13문서의 좌표/배포 계약을 먼저 확인한다. PRISM은표구조/스킬방식/수치표본만,2D외형·과금·광고부활은 사용하지 않는다. 부족한 리그·동작·내비·충돌·FPS팔표현·Cell대열/숫자·UI와 게임규칙만 보완한다. 기존 g03무리/g06굴착/g10러너는 첫범위에서 제외한다. g07길목은p01후속변형, g08보스는공통단계, g02방/g04호위는후속, g09칠하기는정화결과표현으로흡수한다. 파일/자산은삭제하지 않는다. 10문서의마이그레이션대로 기획정본/메뉴/저장백업을 작성하고 구출펫/캐릭터선택/과거결과는 보존한다. 지역5×4카드=20미션은초기캠페인제안이고새missionId를발급한다. 구sID의내용을몰래다른게임으로바꾸지 않는다.

첫작업은 **M0→M1→M2**다.

1. **M0**: 실제 경로·라이브러리·자산·클립·고도·소켓을 확인하고 변경 파일 계획을 작성한다. 04문서의 서비스/타입/표와 고정60틱·불변 snapshot·RNG·입력·세계·HUD·로그·dispose·기획 브리지를 연결한다. 미구현은 NOT_IMPLEMENTED로 차단한다.
2. **M1**: p01의 준비/시설5칸/혼합3웨이브/보스/경제/카드/코어·인간 실패/실제 승리/재시작을 완성한다. 직접 공격은 빠른 탄, 범위포·투석기는 느린 비행 후 착지 피해다. 자유 적의 한 점 집결·한 줄 행렬을 막는다.
3. **M2**: 마을 보관 코드를 이식해 로비→카드→출항→p01→결과→귀환→저장을 연결한다. 제품 실행에 외부5180 개발 서버가 반드시 필요하지 않게 한다.
4. **M3**: p03의 떼·XP 회수·3택·기존7종+추가12패턴·진화4종·보스를 완성한다. 11문서의 패시브 후보7/소유4슬롯, 진화 배율, 피해 원장, VFX/오디오 계약을 지킨다. 미구현 패턴은 카드에 노출하지 않는다.
5. **M4**: p02의 FPS 시점·시선 조작·조준·팔/총·후방 경고를 연결한다. 카메라만 바꾼 월드 리플레이 동일성과 실제 FPS 조작을 별도로 검수한다. 카메라 ray와 월드 총구 앞 벽 충돌을 구분한다.
6. **M5**: p04의 가로 이동·6편대·마디별HP·제거 후 orderIndex 유지·머리 사망 후 몸 이동·탄수/연발/관통·경계 실패·숫자·최종100%를 검수한다. 표의 polyline 길이는 최종 스플라인의 실제 호길이로 다시 계산한다.
