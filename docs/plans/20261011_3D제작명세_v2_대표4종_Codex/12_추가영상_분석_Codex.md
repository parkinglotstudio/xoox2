## 3. 대표 4종에 대한 결론

후더덕형과 탕탕형은 이동/자동 공격·3택 성장·원소/소환·처치/보상 서비스를 공유한다. 후더덕형은 준비/시설/코어/웨이브 종료 조건을 추가하고, 탕탕형은 XP 회수/자유 스폰/생존/최종 보스가 중심이다. FPS는 후더덕형의 시점과 입력 정책을 교체한다. Cell형은 같은 탄/성장 서비스를 사용하되 이동 축·대열 경로·마디 HP·경계 실패·카드 풀이 다르다.

추가 영상 때문에 새로운 게임 엔진을 각각 만들 필요는 없다. 공통 서비스 안에 패턴·정책·표를 등록하고 프로필로 합성한다. 공격 판정은 게임 시간, 카드는 UI 시간, 결과 연출은 판정 확정 이후 시간으로 관리한다. 실제 원게임의 상표/2D 배우/과금/광고 부활은 수스 제작에 복사하지 않는다.

## 4. 재현 자료

추출 스크립트 `evidence/analyze_more_videos.py`를 Python+OpenCV+Pillow 환경에서 실행하면 원본 영상에서 같은 시점 캡처를 재생성한다. 타임스탬프 seek는 압축 영상/프레임레이트에 따라 가장 가까운 디코드 프레임으로 맞춰진다. 메타데이터 fps는 컨테이너 평균이며 정확한 원게임 틱 속도가 아니다.

원본 영상은 ZIP에 포함하지 않는다. 제작자가 원본 영상에 접근하지 못해도 캡처·관찰표·수스 적용 규칙은 읽을 수 있다. 카드 글씨나 모션 판정을 확대 확인할 때는 같은 이름의 원본 파일을 별도로 전달한다.
