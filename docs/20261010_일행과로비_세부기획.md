# 일행과 로비 세부기획

프로젝트: **Soos Arcade**
날짜: 2026-10-10
앞 문서: `docs/20261010_로비까지_시나리오.md`
다음 화면: `docs/20261010_외출카드_기본기획.md`

리소스는 이 문서가 괜찮다고 한 뒤에만 복사한다. 지금은 목록만 적는다.
3D 로비 배경은 코덱스 몫이다.

## 1. 화면 셋

게임 본체로 들어가기 전의 화면은 셋이다.

1. **일행** — 인간 1명, 정화 동물 1마리를 고른다.
2. **인트로** — 처음 한 번. 고른 둘이 들판을 달린다.
3. **로비** — 간판 다섯. 외출만 게임 카드로 간다.

## 2. 일행 화면

화면은 두 줄이다.

- 위줄: 인간 A, 인간 B. 칸은 둘.
- 아랫줄: 3NOFILTER, 해커캣, Flux, Lumos, Gizmo. 칸은 다섯.
- 고른 칸만 밝은 테두리다.
- 인간과 동물이 둘 다 골라져야 **출발**이 켜진다.
- 처음에는 아무것도 골라져 있지 않다.

로비에서 다시 열면 버튼 말이 **돌아가기**가 된다.
이미 고른 둘이 테두리 켜진 채로 보이고, 바꿔도 인트로는 다시 나오지 않는다.

## 3. 인트로

출발을 누른 첫 번에만 재생한다.
구도는 영상 정본을 유지한다. 등 뒤, 밝은 들판, 달리다가 정면으로 돌아 무기를 겨눈다.
고른 동물은 인간 옆에서 같이 달린다.
재생이 끝나면 로비로 넘어간다.
다음 실행부터는 이 화면을 건너뛰고 로비로 들어온다.

## 4. 로비에서 누르는 것

배경 그림은 코덱스가 만든다. 누르는 자리만 여기 고정한다.

| 자리 | 누르면 |
|---|---|
| 선착장 왼쪽 간판 외출 | 게임 카드 6장 |
| 오두막 쪽 기록 | 기존 기록. 이번 기획에서 내용을 만들지 않는다 |
| 가운데 협동 | 기존 협동. 같음 |
| 아래 파견 | 기존 파견. 같음 |
| 오른쪽 모험 | 기존 모험. 같음 |
| 가운데 선 둘 | 일행 화면. 버튼은 돌아가기 |

외출에서 게임을 고르기 전까지 돌아오면, 로비의 둘은 그대로다.
카드에서 시작한 게임이 끝나도 로비의 둘은 그대로다.

## 5. 남아 있는 것

이 세 가지는 기기에 남는다.

- 마지막에 고른 인간
- 마지막에 고른 정화 동물
- 인트로를 이미 봤는지
