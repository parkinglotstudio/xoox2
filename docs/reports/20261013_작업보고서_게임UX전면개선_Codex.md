## 최신 5개 요청의 사용 방법

1. 상단 목표 패널을 따라 이동하고 하단 버튼으로 행동한다. `기술 · 보기`에서 장착 목록을 확인한다.
2. 모든 인간 플레이는 출발 기술을 이미 가진다. p03의 서리 조각은 주변을 회전하며 실제 타격한다. 시작 설명에 그림·이름·효과를 넣었다.
3. FPS의 목적은 3웨이브 동안 정화 코어를 지키는 것. 처음에는 보조 사격이 켜져 있어 이동/시점부터 익힐 수 있다. 끄면 사격 버튼/Space를 눌러 발사한다. 범위 기술과 시설은 별도 자동 지원.
4. HUD는 위쪽의 체력·단일 목표와 아래쪽의 이동/행동으로 나눴다. 시설 포인트는 준비에 표시한다. 보스 HP는 등장 때만 표시한다.
5. `p03 숲이 깨어나는 시간`에 전투 중 주변 복원을 추가했다. `p07 다시 피어나는 섬`은 땅과 장치를 직접 복구하는 별도 정화 게임으로 유지한다.

## 밸런스

HP140·기본 연사10피해·기술6슬롯/패시브3종·최대Lv14. 자동 출발기술1종 + 추가 시작1선택. 일반 성장 최소6초 간격과 시간 보급18초. 최초의 19동시 기술/분당27회 이상 선택은 일반판에서 제거하고 효과 시험에서만 사용한다. 기존 기술 강화/진화 짝을 우선 제시한다.

방어 코어520HP, 시작220정화석(시설만280), 추천 빠른/범위 시설 배치. 생존180초+최종보스, 피해0.75배·초당회복0.65. 체인은 초기3열·6대열·더 느린 진행. 수색은 각 방3무리. 호위는 수레560HP·진행/구조/귀환. 복구는45%/3장치/채집과 3초 작업이다. 모든 적을 한 값으로 처리하지 않고 기존49종의 역할·행동·층·패턴·스폰 경로를 유지한다.

## 검수 결과와 한계

아래 시간은 브라우저에서 실제 고정틱/피해/XP/목표를 실행한 자동 이동·선택 시험이다. 메뉴 선택에 걸리는 사람의 시간은 포함하지 않는다. 각 게임은 실제 브리핑/초기 선택/키보드 이동/시작/재시작도 별도로 조작했다. 자동 목표 확인을 사람이 느끼는 연출의 완성도나 모바일 기기 성능으로 대신하지 않는다.

- 전체 브라우저 오류/HTTP 실패0. 현재 아케이드 범위 TypeScript 통과.
