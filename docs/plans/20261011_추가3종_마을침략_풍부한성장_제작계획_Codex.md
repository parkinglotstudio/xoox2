# 추가 3종·마을 침략·풍부한 성장 제작 계획
작성: Codex · 2026-10-11 · 사용자 확정: 추가 6개를 3개로 통합, 기존 4개 유지

## 컨셉과 전체 흐름
공중마을에서 외출 → 오염된 숲 수색 → 반려동물 발견·구출 → 호위와 탈출 → 정화 시설 복구 → 마을 귀환. 마을에서 반려동물과 생활하며 가끔 날아오는 적을 함께 막는다. 모든 캐릭터·펫·적은 기존 수스 3D 자산을 사용한다. 디자인을 새로 바꾸지 않는다.

## 제작 순서와 승인 범위
1. 기존 성장 수치·카드 후보 다양성부터 보정한다. 2. 기존 맵·내비게이션을 실제 게임 규칙에 연결한다. 3. 새 3종의 준비·전투·목표·승패·재시작을 완성한다. 4. 마을 침략을 연결한다. 5. 기획툴에서 파트별 실행·수치 조절·효과 시험을 제공한다. 6. 실제 입력·승패·저장 분리·리소스 로딩을 검수하고 캡처와 인수인계를 남긴다. 소리·배포 빌드·커밋·그룩 정기 확인은 이번 범위에 없다.

## 성장 체험 우선 수치
무기 슬롯 20, 패시브 종류 7, 최대 레벨 100. 최초 강화 3회, 경험치 필요량 4에서 시작해 레벨당 1.5 증가, 경험치 흡인 16m/회수 1.8m. 전투 시간 6초마다 경험치와 별개로 강화 선택 1회(화면과 게임 시간은 카드 선택 동안 멈춤). 세 선택에는 가능한 한 새 무기·보유 무기 강화·진화 짝 패시브를 포함한다. 진화 조건 충족 카드는 먼저 표시한다. 시설 전용·체인 모드는 각각 시설 보급과 체인 전용 성장으로 처리한다. 이 수치는 최종 난이도보다 많은 효과를 체험하도록 의도적으로 넉넉하게 설정했다.

기획툴의 효과 시험은 시험 모드에서만 허용한다. 무기/진화를 선택해 즉시 적용하며 캠페인 저장과 보상에 반영하지 않는다. 실제 일반 판에서도 빠른 성장이 유지된다. 효과·투사체 수명/캡은 유지한다.

## p05 수색 돌파
기존 forest_rooms 6종(빈 방·암석·기둥·웅덩이·가시·보스)을 차례로 실제 플레이한다. 각 방의 배치/장애물/입구/출구 좌표를 그대로 변환한다. 실제 적 처치 전 출구 잠금, 처치 후 북쪽 출구에 도착하면 다음 방. 마지막 보스 사망 후 구출 표시가 있는 출구에 도착하면 승리. 캐릭터 HP 0 또는 제한시간 초과는 실패. 도달 조건과 전투 조건을 분리해 자동 성공을 막는다. 웅덩이·가시는 경고 뒤 실제 피해를 주며 안전 통로를 남긴다.

## p06 구출 호위와 탈출
sky_route의 시작섬·체크포인트·갈림길·작은 우회섬·종점섬과 다리를 사용한다. cart GLB가 실제 호위 대상이다. 캐릭터가 수레 가까이 있고 주변 적이 적을 때 이동한다. 거리 이탈·적 저지 시 정지한다. 수레와 사람 모두 실제 HP를 가지며 수레 파괴/사람 사망/시간 초과 실패. 종점에서 구출 후 탈출 거점까지 호위, 도착 시 승리. 짧은 길/우회 경로를 선택할 수 있고 체크포인트 보급을 받는다. 공중섬과 다리 밖은 이동할 수 없다. 지도 높이를 배우·효과·카메라에 반영한다.

## p07 정화 복구
기존 landing 상륙섬을 정화 작업 현장으로 재사용한다. 이동으로 정화 셀을 칠하고 오염원 근처에서 작업한다. 한정된 정화석 채집 더미에서 자원을 얻어 시설 3곳을 복구한다. 목표는 실제 정화 면적+오염원 제거+복구 시설 완료 모두 충족. 무한 채굴/자유 블록 월드 엔진은 만들지 않는다. HP 0/시간 초과 실패. 부채꼴 또는 격자 정화 표시와 복구 단계가 화면에서 구별되어야 한다.

## 공통 반려동물 협력
기존 펫 전투를 재사용한다. 전투·회복·감속·정비 등의 역할과 행동 간격은 표에서 관리한다. 펫 하나를 고르고 함께 외출한다. 무리 지휘는 별도 RTS 게임을 만들지 않고 이 협력 기능으로 통합한다.

## 로비 침략 이벤트
평온 → 접근 경고 → 여러 방향 비행 침투 → 방어 → 승리/복구 → 평온. 로비가 보이는 동안만 시간이 누적되고 비접속 벌점은 없다. 기획툴에서는 즉시 발동 가능. 구출 펫 수가 방어 지원에 기여하되 펫 0마리도 기본 시설로 막을 수 있다. 기존 집/마을 영구 손실 없음. 실제 적 HP·투사체 명중·방어 코어 HP와 제한시간으로 결과를 정한다. 시작 상태·경고·남은 적·결과·재시도 표시를 제공한다.

## 기획툴·저장·검수
7게임+로비+카드+침략을 각각 기획툴에서 실행한다. 기존20미션 ID와 진행 기록 보존, 추가 미션은 새 ID로 덧붙인다. 시험은 캠페인 기록을 변경하지 않는다. 수치 변경은 기존 표 저장·검증 흐름을 따른다. 실제 키보드/터치 입력, 모든 목표의 승리/실패/재시작, 문/카트/정화 작업, 카드 누적·진화·다양한 FX, 펫·높이·장애물·카메라·콘솔/네트워크 오류를 확인한다. 검수되지 않은 플랫폼은 보고서에서 구별한다.
