# 리소스 활용 계획

프로젝트: **Soos Arcade**
날짜: 2026-10-10
원칙: 수스에서 만든 리소스를 **전부** 쓴다. 새로 만드는 것은 빈칸만.

> **2026-10-10 갱신**
> - **2D 단독 리소스는 게임에 쓰지 않는다. 3D에 적용된 리소스만 쓴다.** 원인 그림(오염물질·벌레·얼룩·인간 원흉·원흉), 키비주얼 펫, 로비·공통 UI 그림, 섬 지도, 스프라이트, 타일·소품 그림은 기획툴에서 "사용 안 함"으로 표시했다. 아래 표에서 이것들을 쓰는 칸은 지운 것으로 본다. 하늘 그림은 3D 맵이 배경으로 쓰므로 남긴다.
> - **로비 맵 정정:** 로비는 섬 해안이 아니라 코덱스의 **정화숲 공중마을(VILLAGE03)** 이다(`assets/village/releases/VILLAGE03/`, 코덱스가 등록). 섬 해안은 01·04 해안 맵 후보로만 남는다.
> - 수스 툴도 가져왔다: 숲 플레이 통합, 정화 숲·건설과 방어, 프랍 카탈로그, 섬 외곽, 전투 스킬 테스트, 유닛 랩 → http://localhost:5190/tools.html
