# XOOX 브랜드·UI·카드 가이드
작성: Codex · 2026-10-13

## 기준 이미지
assets/arcade/art/UX03/ui-direction.png는 이미지 생성 시안이다. 실제 실행 화면으로 표시하지 않는다. 로고는 사용자가 제공한 청록색 XOOX의 둥근 부피와 부드러운 재질감을 유지한다. 별도 생성 그림은 시나리오의 홍보/카드 그림이며3D 플레이 모델을 새로 정의하지 않는다.

## 디자인 토큰
배경#081827, 패널#102638, 강조#20e1df, 읽기용 글자#fff0d2, 보상#d9ad63. 본문16px/줄간격1.5, 설명14px, 버튼44px 이상. 반짝임은 활성 카드·성공·주요 행동에만 사용. 얇은 내부 테두리와 깊이 있는 외곽 프레임, 적당한 어두운 여백으로 그림과 정보를 나눈다. 지나친 네온/작은 회로 장식/한 화면 많은 패널을 피한다. 색 외에 아이콘·문자·진행 상태도 함께 표시한다.

## 모험 카드
중앙 카드 한 장, 좌우 다음 카드 일부, 그림55% 이상, 제목/사건/목표/예상시간/별. 각 카드는 별도 시나리오 그림. 앞면은 이번 이야기의 분위기, 뒷면은3가지 행동·위험·구출 대상·조작. 넘기기/키보드/스와이프·뒤집기·출발. 출발 버튼은 카드 바깥 아래 한 곳. 잠금 카드는 이유를 보여 주며 캠페인 순서를 지킨다. 제작실은 모두 시험 가능하다.

## 전투
위:게임 제목·단계·작은HP/XP. 중간:월드가 주인공, 단계 알림은짧게. 목표는 위쪽 한 패널에 모으고 아래는 이동/행동 버튼. 장비 목록은 버튼으로 펼친다. 성장 창:신규·강화·진화라는 명확한 분류와 큰 그림/효과/레벨. 설명을 펼쳐도 장문의 수치가 기본 흐름을 가리지 않는다. 시작 브리핑은 언제나 확인 가능하고 단계/기믹 알림은 튜토리얼 비활성에서도 유지한다.

## 제작실
게임별 카드를 고른 뒤 기획/시안/플레이/수치/결과를 따라간다. 기본은 플레이에 집중하고 상세JSON·효과시험·데이터표는 접어서 제공한다. 과거 시뮬레이터와 초기10아이디어는 기록 링크로 보존한다. 실제 구현/시안/미검수 상태를 분리해서 표시한다.
