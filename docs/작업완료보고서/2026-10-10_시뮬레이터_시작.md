# 작업 완료 보고서 — 기획 작성 계획과 시뮬레이터 시작

1. 날짜·시간: 2026-10-10
2. 작업 요약
   - 기획 작성 계획을 썼다(기획서 10장 뼈대, 단계 S1~S8, 도구).
   - 미션 = 게임 타입 + 맵 구조로 바꿨다. 맵 설정서 10개(블렌더 작업 지시), 미션 카드 글자(굵은 문장·하는 법·난이도·판 길이)와 그림 AI용 그림 시안 10개를 넣었다.
   - 본게임 순서 그대로 도는 시뮬레이터를 만들었다: 로비(아래 메뉴 외출) → 미션 카드 → 게임 → 결과 → 다음 카드 → 10개 클리어 시 동물 구출 → 로비. 진행은 브라우저에 저장.
   - 전투 생존 뼈대(A)의 목표 5종(버티기·방 돌파·보스·호위·칠하기)이 실제로 돈다. 나머지 뼈대(B~E)는 성공/실패 버튼으로 흐름만 잇는다.
3. 변경·생성 파일
   - `docs/20261010_기획작성계획.md`
   - `planner/sim.html` (새로)
   - `planner/index.html` 미션·맵 화면, 카드·그림 시안 칸, 시뮬 결과 칸, 시뮬레이터 버튼
   - `planner/data.json` 맵 10, 카드 글자, 그림 시안, 뼈대·목표, 시뮬 결과, 질문 q10~q12
   - `docs/기획서.md` 다시 내보냄
4. 확인·검증: 자동 조작으로 목표 5종을 끝까지 돌렸다. 시뮬 중 버그 3개(호위 변수 누락, 보스가 플레이어 위에 생성, 시작 프레임 음수 시간)를 고쳤다.
5. 시뮬로 찾은 것
   - 버티기: 5분간 피해 0 → 마지막 보스 14초에 체력 140→20. 떼가 약하고 보스만 셈.
   - 방 돌파: 20방 182초. 궁수의 전설과 비슷한 속도.
   - 호위: 남은 시간 1:48. 시간 압박이 없음.
   - 칠하기: 효율적으로 칠해도 3분 53%. 목표 70%는 불가능.
6. 남은 일: B 건설 방어(푸더덕) 시뮬 → C·D·E. 카드 별의 뜻(q12), 칠하기 목표(q11), 바퀴당 미션 수(q10).
