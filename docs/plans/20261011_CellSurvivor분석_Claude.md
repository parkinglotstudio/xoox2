## 1. 한 줄

**위에서 지그재그로 내려오는 긴 세포 사슬(바이러스 지네)을, 아래 방어선의 플레이어가 좌우로만 움직이며 자동 사격으로 깎는 게임.**
사슬의 맨 앞(뿔 달린 보스 머리)이 방어선에 닿으면 진다. 사슬을 다 부수면 이긴다. 센티피드 + 주마(Zuma)식 사슬 + 뱀서류 카드 성장.

## 4. 사슬(적) 규칙 — 영상에서 읽은 것

- **한 줄짜리 사슬.** 정해진 지그재그 길을 따라 한 덩어리로 전진한다. 길은 화면 폭 전체를 오가는 뱀 모양.
- **마디마다 체력.** 앞쪽(먼저 닿는 쪽)이 약하고, 뒤쪽으로 갈수록 강하다 → 시간이 갈수록 남은 사슬이 단단해진다.
- **진행률 = 부순 마디 비율.** 2분에 25% — 첫 판은 지도록 짜여 있다(부활·성장으로 유도).
- **특수 마디** (마디 위 상자 표시):
  - 파란 테 상자: 단단한 마디(보호막). 숫자가 커서 오래 걸린다.
  - 금색·보라 뿔 상자: 보상 마디로 보임(부수면 카드·재화).
  - 노란 얼굴: 강화 마디.
- **사슬 맨 앞 보스 머리**(뿔 달린 갈색 머리): 방어선에 닿으면 패배. 연기를 뿜으며 밀고 내려온다.
- **사슬 맨 뒤 왕관 머리(`원숙`)**: 왼쪽 위 아이콘과 같음 — 사슬의 꼬리 대장. 끝까지 부숴야 하는 목표로 보인다.

## 5. 플레이어와 공격

- 조작: **좌우 이동만**(방어선 위). 사격은 자동, 위쪽으로.
- 기본 공격: 알약(캡슐) 3발 묶음, 위로 직진.
- 추가 공격: 금색 바늘(침) — 사선으로 날아가 사슬을 꿰뚫거나 튕긴다. 폭발·연기 효과도 보임.
- 카드 성장(이번 판에서 본 것):
  - `알약 수량 +2`, `알약 수량 +1` — 한 번에 쏘는 알약 수
  - `사격 가속` — 알약 발사 속도 +20%
  - 속성 계열 5색 표시 — 카드가 색 계열로 묶인다(빨강·노랑·보라·파랑·녹색)
  - 두 번째 카드 묶음: 뼈(?), `소형 의료 타워`(자동 공격 설치물), 막대(?) — 무기·설치물 계열
- 카드 창: 3장 중 1장, `무료 새로 고침`(4회), `전부 획득`(광고, 2회).

## 6. 우리에게 쓸 것 (구조·밸런스·스킬 종류만)

### 6.1 새 게임 구조 후보: **"사슬 막기"**
코덱스 구조 5종 중 **A 전투·생존**의 변형(조작을 좌우 1축으로 줄이고, 적을 "정해진 길 위의 한 사슬"로 바꾼 것).

- 정화숲 공중섬의 굽은 길이나 구름다리를 따라 **복셀 몬스터를 이어 붙인 사슬**(units_free 의 q_ 몬스터 마디)이 내려온다.
- 루온·리아는 정화 코어(또는 등대) 앞 방어선에서 좌우로 움직이며 쌍권총 속사(위로).
- 사슬 맨 앞 = 바퀴별 원인 보스 머리, 맨 뒤 = 꼬리 대장.
- 이기는 조건: 사슬을 다 부숨. 지는 조건: 머리가 방어선 도착.
- 목표 지표: 진행률(부순 마디 %) — 결과 별 기준으로 그대로 쓰기 좋다.

기존 10게임 중 넣을 자리: **g07 길목 지키기의 변형**(정해진 길 + 누출 방어)이나 바퀴별 **추가 미션**. 미션 = 게임 타입 + 맵 구조라 맵만 있으면 미션 카드로 늘릴 수 있다.

### 6.2 밸런스 틀
| 항목 | 영상 값(첫 스테이지, 쉬움) | 쓰는 법 |
|---|---|---|
| 마디 체력 | 앞 100~1,000 → 뒤 4,000~7,000 (앞→뒤로 점점 커짐) | `segment_hp = base × (1 + k × 마디 순번)` 표 |
| 첫 판 결과 | 2분 / 진행률 25% 에서 패배 | 첫 판은 지게 → 성장 유도. (우리 v1 은 영구 강화가 없으므로 첫 판에 깰 수 있게 낮춰야 함) |
| 카드 시점 | 시작 0초 + 약 88초 | 진행률 구간마다(예: 10%·20%…) 카드 |
| 특수 마디 | 단단한(파랑) · 보상(금/보라) · 강화(노랑) | 마디 종류 표: hp 배율 · 보상 · 효과 |
| 부활 | 3회, 부활 시 사슬 대폭 격퇴 | 우리는 광고 없음 → "정화 폭발 1회" 같은 판 안 장치로 대체 가능 |

### 6.3 스킬 종류 (PRISM 발사 방식 표에 더할 것)
| 방식 | Cell Survivor | 우리 대응 |
|---|---|---|
| 위로 다발 직사 + 발 수 증가 카드 | 알약 수량 +1/+2 | 쌍권총 속사의 `projectile_count` 카드 |
| 사격 가속 | 알약 발사 속도 +20% | 쿨 감소 패시브(PRISM energyCube 와 같은 축) |
| 관통·튕김 바늘 | 금색 침(사선) | PRISM drill_shot/축구공 방식 |
| 설치형 자동 포탑 | 소형 의료 타워 | g05·g07 건물 행을 판 안 카드로 |
| 색(속성) 계열 카드 묶음 | 빨·노·보·파·녹 5계열 | PRISM element 5종(화염·냉기·독·광선·전기)에 색을 1:1로 |
