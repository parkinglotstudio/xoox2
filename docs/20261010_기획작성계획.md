# 기획 작성 계획

프로젝트: **Soos Arcade**
날짜: 2026-10-10
정본: 기획툴 `planner/data.json` (화면: `planner/기획툴_열기.bat` → http://localhost:4174/)
내보내기: `docs/기획서.md` (툴에서 자동 생성. 직접 고치지 않는다)

## 1. 기획서의 뼈대

기획서는 아래 10장으로 짠다. 툴의 화면도 이 순서를 따른다.

| 장 | 내용 | 툴 화면 | 상태 |
|---|---|---|---|
| 0 | 개요 — 한 줄 정의, 왜, 수스와의 관계, 플랫폼 | 개요 | 초안 |
| 1 | 화면 흐름 — 로비 → 아래 메뉴 "외출" → 미션 카드 → 게임 → 결과 → 카드 | 개요 | 초안 |
| 2 | 시나리오 — 바퀴(동물 1마리)와 미션 순서, 이야기 한 줄씩 | 미션 | 초안 |
| 3 | 미션 카드 — 미션마다 카드 글자와 그림 시안 | 미션 · 카드 미리보기 | 작성 시작 |
| 4 | 게임 뼈대 5종 + 목표 — 조작이 다른 뼈대와, 그 위에 얹는 이기는 조건 | 게임 타입 | 제안 |
| 5 | 공통 시스템 — 이동, 자동 공격, 스킬 카드, HUD, 바닥 초상, 결과·보상 | (새로) | 미작성 |
| 6 | 맵 설정서 — 맵마다 크기·배치·스폰·소품·분위기. 블렌더 작업 지시서 | 맵 | 초안 10개 |
| 7 | 리소스 — 수스에서 가져올 모델·발사체·맵 | 리소스 | 초안 |
| 8 | 수치표 — 시뮬레이터로 맞춘 숫자 | 시뮬레이터 | 미작성 |
| 9 | 결정·질문 | 결정·질문 | 진행 중 |

## 2. 미션과 게임의 관계

- 미션 = 뼈대 + 목표 + 맵.
- 외출을 누르면 이번 바퀴의 미션 수만큼 카드가 나온다. 왼쪽부터 차례로 깬다.
- 게임 뼈대는 5종이다(제안).

| 뼈대 | 손 | 목표 예 |
|---|---|---|
| A 전투 생존 | 원판 이동, 자동 공격 | 버티기 · 방 돌파 · 보스 · 호위 · 칠하기 |
| B 건설 방어 | 칸 눌러 세우기 | 거점 지키기 · 길목 지키기 |
| C 무리 지휘 | 던지기, 불러 모으기 | 부품 나르기 |
| D 지형 파기 | 깨기, 쌓기 | 아래로 내려가기 |
| E 추격 러너 | 좌우, 점프 | 탈출 |

## 3. 작성 단계

| 단계 | 할 일 | 나오는 것 | 끝난 기준 |
|---|---|---|---|
| S1 | 구조 확정: 뼈대 5종 + 목표, 바퀴당 미션 수, 별의 뜻 | 결정 기록 | 질문 q10·별이 닫힘 |
| S2 | 미션 카드: 1바퀴 미션 카드 글자 + 그림 시안 | 카드 미리보기, 그림 AI 지시문 | 카드 10장이 미리보기에 다 찬다 |
| S3 | 시뮬레이터 A: 전투 생존 뼈대 + 목표(버티기·보스) | `planner/sim.html` | 수치를 바꿔 한 판을 돌리고 결과를 본다 |
| S4 | 공통 시스템 설계서 | 기획서 5장 | 코딩에 필요한 규칙이 다 적힘 |
| S5 | 시뮬레이터 확장: A의 나머지 목표 → B → C·D·E | 시뮬레이터 | 뼈대 5종이 다 돈다 |
| S6 | 수치표 확정 | 기획서 8장 | 시뮬 결과로 숫자가 정해짐 |
| S7 | 맵 설정서 확정 → 블렌더 | 기획서 6장, 블렌더 파일 | 맵 10개 설정이 확정 |
| S8 | 3D 프로토타입 | 첫 미션 한 판 | 실제 기기에서 한 판 |

## 4. 카드 그림

- 그림은 그림 AI가 그린다. 기획서에는 미션마다 **그림 시안**을 적는다.
- 시안에 적는 것: 구도, 등장(누가 무엇을 하나), 배경, 색, 분위기, 스타일, 비율, 비워 둘 자리, 넣지 말 것.
- 공통: 세로 3:4. 아래쪽 40%는 글자가 올라가므로 어둡게 빠지는 여백. 글자·로고를 그리지 않는다.
- 레이아웃(글자 배치)은 HTML로 따로 잡는다: 시뮬레이터 카드 화면. 그림이 나오면 미션의 `artImage`에 경로를 넣으면 카드에 바로 뜬다.

## 5. 도구

| 도구 | 파일 | 하는 일 |
|---|---|---|
| 기획툴 | `planner/index.html` | 모든 기획의 정본. 고치면 바로 저장 |
| 시뮬레이터 | `planner/sim.html` | 로비 → 외출 → 미션 카드 → 게임 → 결과 → 구출까지 본게임 순서대로 돌려 본다. 게임은 2D 위에서 보기로, 수치를 바꿔 가며 확인 |
| 카드 레이아웃 | `planner/sim.html?screen=cards` | 시뮬레이터의 미션 카드 화면이 곧 카드 레이아웃이다 |
