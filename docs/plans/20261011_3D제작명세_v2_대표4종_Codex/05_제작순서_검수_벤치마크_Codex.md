## 2. 밸런스 계산과 테스트

초기값의 DPS/스폰수/총HP/필요비용을 먼저 계산한다. 그 다음 무적없는 첫지역·펫없음·기본빌드·고정seed10개로 실제실패원인을 본다. 좋은 봇 결과를 사람의 재미/시야/조작 검수로 대신하지 않는다.

| 유형 | 필수 지표 | 문제 판단 |
|---|---|---|
| p01 |처치시간·코어접근수·시설당명중/DPS·비용·잔여HP·병목|약한적도오래쌓이는지, 범위포가실제다수를맞히는지 |
| p02 |위지표+시야내표적·엄폐막힘·조준오차·후방피격·회전량|규칙동일성과시점난이도차이를분리 |
| p03 |성장시각·XP회수율·진화시각·적밀도·피격원인·실효DPS|초반처치/후반빌드의성장감, 급습회피방향 |

p04 기본40DPS에 명중률50%면20실효DPS다. 첫편대 기본HP336에보상/장갑증가가더해져 약17~20초이상 필요할 수 있다. 실제 경로 ETA와첫강화효과를비교한다. 탄수가늘어도같은표적을못맞히면DPS계산을그대로성공예측에쓰지않는다. 경로호길이는제작된실제좌표로계산하며 화면의줄수×가로폭 추정에만의존하지않는다.

한번에 관련변수1~3개만 바꿔 동일seed·설정전후를비교한다. HP를내리면서스폰수/속도도함께올려변경효과를감추지않는다. 실패가 예고/카메라/총구벽에의한것이면 공격력상향만으로해결했다고하지않는다.

첫사람검수는 게임별6명×4seed=24판 권장, 조작경험/장치/프로필/성공/실패를기록. 학습후보통성공60~80%,어려움30~50%는 목표이며통계적으로보장된값아니다. FPS대표에특정벤치마크영상이제공되면그조작을추가검수하고현재제안을아무근거없이원작수치로명명하지않는다.
