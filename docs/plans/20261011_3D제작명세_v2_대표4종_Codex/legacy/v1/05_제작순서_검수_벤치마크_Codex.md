M0/M1이 ‘이어 제작할 수 있는 초기 수준’이다. 이번 패키지는 그작업의파일 구조·인터페이스·초기수치·검수설계를제공한다. 실행코드의M0/M1완료로 보고하지 않는다. M단계마다작동하는부분을제품수준으로끝내고다음단계로간다. 임의 성공버튼으로 10게임완료표시하지않는다.

각단계산출물: 코드/데이터변경목록, 실제리소스목록, 정상·실패·재시작로그,스크린샷(전체/상호작용/결과), 짧은플레이영상,성능장치정보,미완료 사항. 다른AI는완료한단계·다음단계·재현명령을문서에남긴다.

## 2. 공통 검수 체크리스트

1. 4사람외형·5펫실제 자산 로드, 없는클립/소켓오류를표시. 두사람동일규칙.
2. 이동+행동멀티터치, 입력 해제/숨김/일시정지/카드 선택,30/60fps게임속도일치.
3. 바닥높이/계단/다리/낭떠러지, 내비와실제콜라이더 일치.
4. 빠른탄 연속충돌, AoE대상별 1회, 관통/연쇄/DoT중복, 죽은표적예정공격취소.
5. 3택유효후보, 최대레벨·슬롯·진화·HP증가·코스트, 선택중틱정지.
6. 몬스터 2~3종동시스폰/다른길·속도, 분산·혼잡·막사대기, 모두한점집결없음.
7. 비용/환급/업그레이드·wave호출·구출·결과 1회처리, 정수경제음수없음.
8. 명시적실패와abort, 재도전초기화, 테스트결과의캠페인격리.
9. 메뉴진입/뒤로/같은화면재진입, 세션전환 20회 후 메모리·구독·자원 누적없음.
10. 미션/로비/카드/연결플레이가같은publishedconfigHash를사용.
11. dev URL과배포assetURL모두검증, extGPUinstancing, 비동기로딩실패/취소.
12. 실제 플레이스크린샷은실행빌드·seed·시간·게임·설정 해시와함께저장.

미션별검수는 02문서의조건을모두수행한다. 파일문자열존재검사는기능검수의대체가아니다. 봇은재현·도달성/상한/경제오류검사용이고사람의재미·난이도판정을대신하지않는다.

## 3. 밸런스 조정 절차

먼저피해/명중/생성수/경제가계산과맞는지확인한다. 다음무적꺼짐·기본빌드·첫 바퀴펫없음·동일seed10개로실패원인을본다. 자동플레이가통과해도일반사람이길을읽지못하면UI/예고/배치를조정한다.

| 측정 | 기록할 항목 | 초기 목표 |
|---|---|---|
| 클리어 | 게임·바퀴·캐릭터·펫·조작경험·성공/실패 | 초보학습후보통 60~80%, 어려움 30~50%를실제 사람표본으로확인 |
| 시간 | 준비/선택제외실제 플레이·목표·보스타임 | 02의예상범위, 특정종/장애에서장기정지없음 |
| 화력 | 명중률·실제DPS·적잔여수·적처치 시간 | 잔챙이 1발과정예역할이보이며과도한쌓임없음 |
| 경제 | 시작/처치/보급/사용/환급/잔액 | 기본빌드구성가능, 선택한시설의대응효과가드러남 |
| 생존 | 피격시각·출처·누출·소실·재오염 | 실패원인이화면에서읽히고회피/선택으로개선가능 |
| 표현 | 예고선·공격 모션·FX·피해시각 | 타격순서와실제 효과가일치 |

사람평가시최소 6명×seed4개=24판/게임을권장하고표본수·경험차이를함께기록한다. 적은표본으로성공률이통계적으로확정되었다고보고하지않는다. 보통/어려움의프로필을따로버전관리한다.

조정단위: 한번에문제와관계된 1~3변수, 전/후동일seed·입력/사람조건을비교. HP를내렸다면공속·생성률을동시에올려원인을감추지않는다. UI가원인인실패는무작정공격력을올리는대신예고·시야·타격읽힘을먼저고친다.

별·시간·점수는게임별실적. 서로다른게임에서HP기준하나로일괄 3별을주지않는다. 무적·강제승리·시간 8배·봇 결과는testOnly이며다음미션·펫·별을열지않는다.
