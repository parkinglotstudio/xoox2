# 작업 완료 보고서 — 정화숲 툴 가져오기와 리소스 열기

1. 날짜·시간: 2026-10-10
2. 작업 요약
   - 수스의 정화숲 툴 3개(숲 플레이 통합, 정화 숲·건설과 방어, 숲맵 프랍 카탈로그)와 섬 외곽 툴을 코드째 가져왔다. 필요한 소스 31개를 import를 따라가며 골라 복사했다.
   - Soos Arcade를 vite 프로젝트로 만들었다(three 0.185.1, vite 5.4.21 — 수스와 같은 버전). 웹 루트는 assets/susu(수스의 data와 같은 구조).
   - 수스 코드가 data/ 를 직접 부르던 JSON 4곳만 assets/susu/ 로 경로를 바꿨다. 저장 플러그인도 assets/susu 에 쓰도록 바꿨다.
   - 숲 맵 목록이 가리키는 v3 길찾기·건설 자리 데이터를 추가로 복사했다.
   - 리소스 뷰어를 새로 만들었다(모델 동작 재생, 그림, 수치 파일, 폴더 목록).
   - 기획툴 리소스 화면 42개 줄에 "열기" 버튼: 맵은 해당 툴, 나머지는 리소스 뷰어로.
3. 변경·생성 파일
   - `forest-map-tool.html`, `forest-play-tool.html`, `forest-prop-tool.html`, `island-coast-tool.html`, `tools.html`, `viewer.html`
   - `src/` (수스 소스 31개 + `src/tools/viewer/main.ts`)
   - `package.json`, `tsconfig.json`, `vite.config.ts`, `scripts/vite-layout-save.ts`, `scripts/build-asset-index.mjs`
   - `assets/susu/maps/forest150/manifest.json`, `releases/v3/`, `assets/susu/_index.json`
   - `planner/index.html` (열기 버튼), `planner/기획툴_열기.bat` (툴 서버도 함께 켬)
4. 확인·검증: 타입 검사 통과. 툴 4개와 뷰어가 브라우저에서 열림(숲 플레이 "준비됨", 건설과 방어 맵 로드, 프랍 43개, 리아 동작 18개). 기획툴 열기 경로 확인.
5. 실행: `planner\기획툴_열기.bat` → 기획툴(4174) + 툴 서버(5190). 툴 목록은 http://localhost:5190/tools.html
6. 남은 일: 숲 플레이 툴 안의 유닛 랩·블록 고양이·오브젝트 툴 링크는 아직 안 가져와서 열리지 않는다. 리소스를 새로 복사하면 `node scripts/build-asset-index.mjs` 를 다시 실행.
