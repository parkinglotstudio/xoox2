# 한 판 밸런스와 측정 계약
작성: Codex · 2026-10-13

## 이전 문제
1분에27회 이상 선택,19개 동시 기술은 처치보다 메뉴 선택이 반복되는 경험이다. p04는16초대에 방어선을 넘는 사례가 있어 시작 설명·초기 사격·대열 속도를 함께 보정해야 한다. p05~7의 목표 자동 입력 검증은 사람이 느끼는 길찾기·이야기·기믹 검증을 대신하지 않는다.

## 적용할 기준
공통 인간HP140/기본 연사 피해10, 공격 기술6슬롯/보조3종, 최대레벨14, 자동 장착 기술1종 + 추가 시작1선택, 보급18초 간격, XP 시작20·레벨당6, 정화 구슬 흡인6m/회수1.5m. 보조 펫은 공격·회복·감속·수리를 유지한다. 기본 적은 초반1~3회 사격 안에 정화, 정예는2~4초, 최종 보스는 강화된 공격으로10~25초를 목표로 한다. 무조건 모든 적을1발로 죽이는 방식은 보스·방패·범위 공격 구별을 없애므로 일반 적과 구별한다.

방어: 세 웨이브, 초반 직접 포탑으로 길을 읽고 중반 범위/감속을 섞는다. 사망 복구와 준비 보급을 제공. 생존:180초에 최종 보스,85~95초 중간 보스, 초반 최대12→중반30→후반55의 압박. 체인:초기3열 사격을 기본 제공하고 숫자·보급·경계를 설명, 대열 속도를 낮추되 제거 속도도 실제 측정. 수색:방4/5의 기믹과 보스방을 분명히 구분. 호위:길이 아니라 구조 작업과 귀환이 목적. 복구:이동·채집·복원 변화가 화면에서 분명해야 한다.

## 검수 기록
정상 입력: 이동, 메뉴 버튼, 카드 선택, 작업 키를 사용한다. 시험 가속은 같은 고정틱 판정을 돌리되 정상 시간·메뉴 중단 경험과 구별해 보고한다. 판정 주입은 실패 UI를 확인하는 용도로만 쓴다. 시드 최소3개, 초반60초 선택 횟수/기술 수/처치/HP, 실제 승리 목표, 실패/재시작, 효과4진화, 캠페인/시험 저장 분리, 콘솔·HTTP 오류를 기록한다. 모바일 GPU/긴 사용자 플레이 검수 전에는 최종 상용 밸런스로 표현하지 않는다.
