# 미션 맵 (Soos Arcade)

작성: Claude · 2026-10-10

로비(코덱스 **정화숲 공중마을 VILLAGE03**)와 같은 세계로 만든 미션 맵이다.
밝은 복셀 바다 위의 **오염된 공중섬**에서 미션이 벌어진다. 같은 배치를 **정화판·오염판** 두 벌로 낸다.

- 블록 방식은 공중마을 빌더와 같다: 상자마다 정점 색(Col), 면마다 밝기 차이, 재질은 블록 1개 + 빛 1개(`Arcade_Glow`: 등불·문판·정화 코어).
- 나무·바위·꽃·유물은 수스 **정화숲 v7 카탈로그 조각**(정화/오염 짝)을 그대로 놓는다.
- 바다는 glb 에 없다. 공중마을처럼 툴이 그린다. 미리보기 그림에만 바다 판을 깔았다.
- 좌표: 블렌더 X=동, Y=북, Z=위(m). three.js 에서는 x=X, y=Z, z=-Y.

| 폴더 | 미션 | 내용 |
|---|---|---|
| `forest_rooms/` | 02 숲길(방 돌파) | 방 모듈 6종. 방 하나 = 공중섬 하나(놀이 바닥 12×18m), 남쪽 다리로 들어와 북쪽 문 → 다음 섬 |
| `sky_route/` | 04 구름다리길(호위) | 공중섬 5개를 다리로 이은 120m 길. 80m 에서 짧은 길/먼 길 갈림 |
| `landing/` | 01 상륙 섬(떼 버티기) | 60×60m 큰 섬, 남쪽 선착장(비행선), 통 무더기 5곳, 북쪽 둔덕 |
| `props/` | 04·05·07·03 | 정화 수레, 등대, 신호탑 |

파일마다: `*_purified.glb`, `*_polluted.glb`, `*_layout.json`(시작점·문·스폰·위험 지역), 미리보기 그림.
블렌더 원본: `art-source/maps/<폴더>/`. 다시 만들기: `scripts/maps/<이름>.py` 를 Blender 5.2 로 실행.

```
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b -P scripts\maps\forest_rooms.py
```

웹 경로: 툴 서버(vite, 5190)에서 `/assets/maps/<폴더>/<파일>` 로 열린다(수스 복사본의 웹 루트 `/maps/...` 와 겹치지 않게 일부러 나눴다).
