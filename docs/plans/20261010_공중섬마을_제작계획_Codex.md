# 수스 아케이드 — 공중섬 마을 로비 제작 계획

작성: Codex · 2026-10-10  
현재 단계: VILLAGE03 생활 미리보기·바다·24시간 하늘·내비·부유·폭포·비행선·새 및 검증 완료 / 건물 상세·실제 메뉴 연결 후속

## 1. 제작 기준

- 새 게임에서 루온·리아와 반려동물이 지내는 마을을 만든다.
- 바다 위 공중섬, 서로 다른 집 5채, 나무다리, 배가 떠나는 선착장을 포함한다.
- 사용자 첨부 구도와 생성한 이미지 시안을 최대한 재현한다. 전경 선착장·배·캐릭터, 오른쪽 메인 집·펫 마당, 후경 나머지 4채·바다의 깊이 관계가 기준이다.
- 정화숲의 복셀 형상·녹색과 청록색 식생·따뜻한 조명, 기존 사람·펫 디자인을 유지한다.
- 로컬 Blender 5.2로 실제 형상을 만들고 편집 가능한 .blend, GLB, 제작 스크립트, 배치·카메라·조명 데이터를 남긴다.
- 작업 루트는 C:/Users/dmaxd/Downloads/xoox-master/xoox-master이다. 최상위 xoox-master는 압축 해제용 래퍼다.

## 2. 완료한 준비

162개 파일, 137.81 MiB를 새 프로젝트로 복사했다. 모든 파일의 원본/사본 SHA256이 동일하다. GLB 97개의 헤더·전체 길이·외부 버퍼/이미지 의존성을 확인했다.

| 종류 | 복사 내용 | 마을의 우선 사용 대상 |
|---|---|---|
| 정화숲 v7 | 배포 자료·43종 양쪽 변형 카탈로그·Blender 원본·검수 이미지 | 정화 후 수목 6종, 식생·소품 8종, 바위 2종 |
| 사람 캐릭터 | 루온·리아 기존형/3.5등신 4개 모델과 제작 원본·참고 그림 | 기존 얼굴·의상·리그와 각 18개 동작 |
| 반려동물 | NoFilter, Flux, Lumos, Gizmo, 블록 고양이와 제작 원본 | 기존 대기·걷기·달리기·앉기/서기 동작 |
| 하늘·조명 참조 | 정화숲 상태별 하늘 이미지와 원본 manifest | 정화 후 색감을 새 카메라와 장면 규모에 맞게 조정 |
| 구도 그림 | 사용자 첨부와 생성 시안 | 카메라·배치·실루엣·재질의 비교 기준 |

- 우선 사용 목록: [imported_assets.json](../../data/village/imported_assets.json).
- 파일별 경로·해시·실제 GLB 동작: [복사 검증 목록](village/imports/20261010_resource_inventory_Codex.json).
- 신규 프로젝트에 같은 이름의 하늘 이미지가 달라서 해당 파일을 덮어쓰지 않았다. 정화숲 하늘 사본은 data/village/reference/forest_sky/에 따로 보관했다.
- 원본 숲 manifest와 가져온 과거 제작 문서는 출처 확인용이다. 오래된 작업 지시나 전투·이동 의존성을 새 로비 설정으로 사용하지 않는다.
- 완성 숲 맵·이전 건물 자료도 라이브러리에 보존하지만, 마을에서 실제 배치하는 자산만 로드한다.
- 사람 모델은 4개 모두 18클립이다. 추가 펫 4종은 각각 8클립, 기존 블록 고양이는 6클립이다. 고양이의 달리기 등 필요한 추가 동작은 별도 제작 여부를 확인한다.

## 3. 집 5채 — 모두 새로 제작

용도는 외형을 구분하기 위한 가칭이다. 각 집과 게임 메뉴의 연결은 아직 결정하지 않았다.

| ID | 시안의 형태 | 제작할 디테일 |
|---|---|---|
| house_main | 오른쪽의 큰 박공지붕 주거집 | 주황 계단 지붕, 처마, 목조 골조, 크림 벽, 깊이 있는 창·문틀, 현관·테라스·차양·등·덩굴 |
| house_pet | 왼쪽의 낮고 넓은 펫 집 | 청록 다층 지붕, 발바닥 장식, 낮은 출입구, 휴식 데크와 화단 |
| house_garden | 뒤쪽의 정원집 | 연두 지붕, 온실 창, 층별 화분·덩굴과 정원 테라스 |
| house_workshop | 중앙 뒤쪽 공방형 주거집 | 비대칭 주황 지붕, 목조 작업대, 작은 청록 코어, 기계 장식과 베란다 |
| house_lookout | 오른쪽 뒤쪽의 전망 주거집 | 크림·푸른 지붕, 높은 상층, 전망창, 발코니·난간과 항해 장식 |

색상뿐 아니라 지붕, 높이, 창, 현관의 형태를 다르게 만든다. 외관·현관·데크와 가까이 보이는 생활 소품까지 제작한다. 실내 방과 실내 이동은 별도 범위다.

## 4. 제작 순서와 검수 산출물

### 단계 0. 리소스 복사·검증 — 완료

원본을 보존하며 새 프로젝트에 라이브러리를 복사했다. 배포 GLB와 Blender 원본을 함께 보관했다. 실제 클립 이름과 파일 해시를 기록했다.

### 단계 1. Blender 카메라와 전체 배치 — 완료

1. 시안 이미지를 카메라 배경으로 놓고 16:9의 같은 시점을 맞춘다.
2. 선착장·배, 메인 섬·집, 뒤쪽 4개 섬·집을 간단한 입체 덩어리로 배치한다.
3. 실제 주민 모델로 문·계단·난간·마당의 크기를 확인한다.
4. 5채의 지붕과 공중섬 아래 공기층이 보이게 배치하고, 바다가 보이는 여백을 확보한다.
5. 공중섬에서 수면의 선착장까지 내려가는 계단과 연결부를 연속적으로 만든다.

산출물: 전체 배치 .blend, 시안과 같은 각도 렌더, 나란히 비교 이미지.  
검수: 화면상의 위치, 집/캐릭터 상대 크기, 지붕 폭·높이, 섬의 높이, 배와 다리의 연결.

### 단계 2. 메인 집·선착장·배의 세밀 제작

가장 크게 보이는 부분부터 완성한다.

- 지붕: 블록 단위, 겹침, 처마 두께, 모서리와 지붕 아래 음영.
- 벽: 골조와 크림 벽의 단차, 창틀 깊이, 문·현관 계단, 포치 기둥과 차양.
- 생활 소품: 등, 화분, 덩굴, 목재 작업대, 상자, 작은 항해 장식.
- 선착장: 판자 방향, 끝단, 기둥·난간·계단, 계류 고리와 줄.
- 배: 선체·갑판·천막·좌석·화물. 사용자 추가 지시에 따라 부유 장치·추진부가 있는 비행선으로 만들고 선착장 정박 높이와 공중 항로를 확인한다.

산출물: 메인 집·배·선착장 각각의 .blend/GLB, 전체 및 지붕·창·현관·배 근접 렌더.  
검수: 원본 시안의 큰 구조가 유지되며 가까이 보아도 평평하거나 떠 보이지 않는지 확인.

### 단계 3. 나머지 집 4채·공중섬·다리

- 서로 다른 지붕·벽·창·현관을 제작하고 목재/석재 공통 부품은 재사용한다.
- 집마다 앞·옆·뒤 외형을 만든다. 시안에서 보이지 않는 뒷면은 같은 구조 규칙으로 완성한다.
- 공중섬은 잔디 윗면, 층진 토양, 매달린 암석 하단, 이끼와 덩굴을 분리해 만든다.
- 다리에는 주민 이동 폭, 난간, 기둥, 연결 높이를 확보한다.

산출물: 집 5채 완성본, 공중섬·다리 GLB, 각 집과 섬 하단 비교 렌더.

### 단계 4. 정화숲 조경과 주민 배치

- 가져온 나무·관목·꽃·바위를 우선 사용하고 부족한 화분·덩굴·목재 소품을 추가한다.
- 루온·리아와 펫의 실제 원본 모델을 배치한다. 생성 시안의 얼굴로 기존 모델을 바꾸지 않는다.
- 기존 머리카락·귀·꼬리 동작, 눈 깜박임과 대기 동작을 확인한다.
- 펫의 대기·둘러보기·걷기·짧은 달리기·앉기/서기를 마당에서 자연스럽게 연결한다.
- 얼굴과 펫 코어가 어둡거나 과노출되지 않게 빛과 그림자를 조정한다.

산출물: 주민이 있는 전체 렌더, 캐릭터·펫 근접 렌더 및 동작 검수 기록.

### 단계 5. 새 프로젝트의 3D 마을 미리보기 — 생활 기능 선행 완료

현재 파일: village-lobby-tool.html / src/tools/villageLobby/. VILLAGE03을 사용하며 집·지역·주민·펫·비행선 보기, 시간·생활·표현·경로 제어가 구현되어 있다. 실제 메뉴와 출항 후 게임 전환은 후속 기능이다.

- 한 3D 장면에서 집·조경·주민·펫을 함께 표시한다.
- 시안 구도 고정 보기, 자유 회전/확대, 집 선택, 주민/펫 선택, 동작, 조명 강도, 성능 수치를 제공한다.
- 이번 가로 시안으로 먼저 검수한다. 기존 소스는 세로 9:16 로비이므로 최종 화면 비율과 로비 연결 방식은 별도로 확정한다.
- 실제 메뉴의 목적지·출항 후 게임 흐름은 별도 기능 정의에 따른다.

산출물: 새 프로젝트에서 직접 볼 수 있는 미리보기, 같은 카메라의 Blender/브라우저 비교 스크린샷.

### 단계 6. 최적화·문서화

- 정적인 지붕·벽·데크는 색/재질별로 합치고 반복되는 창·기둥·나무·꽃은 인스턴싱한다.
- 가까운 장식에는 작은 블록, 큰 구조와 먼 건물에는 큰 단위를 사용한다.
- 바다는 수면과 잔물결·반사로 표현한다. 복셀 섬과 연결되는 색과 밝기로 맞춘다.
- 삼각형, 드로콜, 재질, 그림자 비용과 로딩 시간을 실제 장면에서 측정한다. 이미지 시안의 세부 블록을 모두 독립 오브젝트로 만들지 않는다.
- 얼굴 그림자, 모델 관통·깜박임, 다리의 끊김, 펫 이동·앉기 전환을 확인한다.
- 최종 .blend, GLB, 제작 스크립트, 배치·카메라·조명, 실행 방법, 스크린샷과 완료 보고를 남긴다.
