# 전체 작업 이력과 근거
작성: Codex · 2026-09-27

현재 제작 방법은 [01](01_캐릭터_제작방법.md), 실행 방법은 [03](03_실행_검증_복구.md)를 따른다. 아래는 이 대화의 자산·툴 작업 흐름이다. 이전 보고서의 수치와 “미구현” 항목은 그 작성 시점의 상태이며 최신 기능과 혼동하지 않는다.

## 1. 기획을 이해하던 단계
- 사용자가 제공한 후더덕 서바이벌 영상에서 이동→표시된 자리 활성화→준비→전투 압박 시작의 박자를 분석했다.
- 수스는 필러 채팅, 원버튼 조작, 자동 사냥을 유지한다. 사용자가 낮/밤을 핵심으로 해석한 초기 접근을 바로잡았다.
- 초기 “샘·기둥 두 자리” 제안은 전진하며 설치·웨이브·구출·정화가 이어지는 사용자의 전체 요구를 담지 못했다.
- Cursor가 전진 자동 웨이브/시퀀스를 만들고, 이 작업은 캐릭터·적·설치물 시각화와 리소스 실험으로 진행됐다.
- 위 기획 대화는 제작 배경이다. 이 문서가 전투 밸런스나 맵 설계를 새로 확정하지 않는다.

## 2. 점구름·블록·무료 모델
1. Blender로 적 구름, 총/던지기 블록, 설치 칸, 구출 표식, 방랑자 기준, 기관총 탄, 폭탄 등 초기 8유닛 제작.
2. GpuCloud로 모이기·솟기·퍼지기·피격·정화 등 GPU 연출을 구현.
3. file://로 열어 빈 화면이 되던 문제에 서버 주소 안내를 추가하고 좁은 화면 카메라를 수정.
4. 레고 계열과 사이버 계열 팔레트 시험. 사용자가 조형과 가독성이 부족하다고 판단.
5. Kenney Tower Defense 24개와 Quaternius 몬스터 45개, 69개 무료 CC0 모델을 도입.
6. 원본 재질을 읽어 점 색을 샘플링. 재질 없는 보조 구 때문에 섞이던 회색 점을 제거.
7. 원본 메시와 점구름을 나란히 비교. 사용자가 형상을 알아보기 쉬운 블록으로 전환 요청.
8. dense.bin 표면 샘플을 받아 셀 크기별 voxelize, InstancedMesh 블록과 원본 나란히 보기 제작.
9. Survival/Factory 및 조립 탑 30개 추가, 총 99개 목록.
10. 부위마다 따로 만든 블록의 격자 충돌·z-fighting을 뼈별 단일 격자와 가중 색 선택으로 수정.
11. 내부 채우기·노출 면 제거·같은 색/AO 면 합치기의 greedy 메시 제작.
12. 대기에는 합친 메시, 흩어짐 등에는 낱개 블록을 쓰는 VoxelUnit과 AO·재질·조명 보강.
13. 포탑의 받침 yaw/포신, 반동·총구, 적의 원래 근접 애니메이션을 구운 블록 프레임을 전투 미리보기에 연결.

### 성능 연구의 결론
점 개수·화면 면적·CPU 갱신·draw call·그림자·효과 방식에 따라 비용이 다르다. “점구름이면 무조건 가볍다”는 결론은 채택하지 않았다. 현재는 형상 가독성과 클로즈업을 위해 블록을 쓰고, 불필요한 면과 동적 계산을 줄이는 방향이다.

과거 보고서의 해당 PC 측정:
- 들판 CPU 점 갱신 약 32.6만 점: 약 48.7ms.
- 고양이 클로즈업 120마리: 낱개 블록 59ms → greedy 적용 12.8ms.
- 2048 그림자와 환경광 재질 바닥 비용을 줄이고 1024 그림자·Lambert 바닥을 사용한 실험.

장면·렌더 경로가 다른 수치를 현재 캐릭터 네 가지의 성능 수치처럼 사용하지 않는다. 모바일 실기기 보장은 없다.

### 배경·하늘·정화 단계 요청과 현재 연결

- 기존 게임 데이터를 보존하면서 툴에 블록 배경·바닥·하늘과 정화 단계 표현을 적용하라는 요청이 있었다.
- 현재 유닛 랩은 공용 `src/maps/blockMap/BlockMap.ts`의 loadBlockMap을 사용한다. MapLab.ts는 같은 뷰를 재노출하는 호환 파일이다.
- 지역 i11/i21, 상태 polluted/purified를 읽어 맵 GLB·원경·하늘색·안개·광원을 함께 선택한다. 현재 이 로더의 상태는 두 가지이며, 게임의 정화 3단계가 모두 구현됐다는 뜻은 아니다.
- 맵과 원경의 실제 제작은 다른 작업자의 공유 자료다. 여기서는 캐릭터 툴의 연결 관계를 기록하며 맵 파일은 수정하지 않았다.

## 3. 초기 방랑자와 얼굴 실험
- 로비 앞모습과 원본 스프라이트를 보고 입체 몸·옷·배낭·랜턴·머리를 Blender로 제작.
- 처음에는 부품을 본에 붙이는 피규어 방식, idle/walk/run 3동작.
- 사격·투척·이동 사격/투척·무기 든 이동을 추가해 8동작.
- 본 로컬축 실측으로 반대로 움직이던 팔과 다리의 회전 부호 수정.
- 총쏘기2를 추가하고 투척 팔 높이·어깨 목표 IK·무릎 반동을 반복 보정.
- KayKit Rogue/Barbarian을 참고해 머리 볼륨·앞머리·옆머리·아호게와 큰 눈을 연구.
- 픽셀 얼굴 A/B, 고해상도 얼굴 판, 입체 눈알 판·각막·속눈썹·눈꺼풀 모프 실험.
- B2는 제공 시안에 맞춰 앞머리, 얼굴, 뒷머리 갈기, 볼륨, 머리 장식 등을 반복 수정.
- C 등록과 비교를 거쳤다. 이 시기의 A/B/B2/C는 과거 실험군이다.

현재 이름 루온의 원본은 2026-09-26의 새 A 제작본이다. 초기 A라는 이름과 같다고 파일을 교환하면 안 된다.

## 4. 리아의 원본 정합 제작
- 기존 실험과 별도로 D 형상을 제작하고 그림의 기준점을 측정.
- 얼굴 깊이·눈 모양·초록 눈썹·앞머리 가르마·민트 끝색·볼 하단을 반복 수정.
- 눈/입의 얕은 홈, 턱 아래 음영, 목 연결, 밝은 카라 확대.
- 머리 다발의 AO, 브로치 잎/꽃, 얼굴 모서리 노출, 동작별 끝머리 움직임.
- 캐릭터 nativeBlocks 경로로 기존 유닛 툴에 등록.
- 쌍권총과 사각 바주카, 대기/이동 중 등 거치, 발도/납도 4클립.
- 팔과 함께 움직이는 어깨 옷, 두꺼운 윗꼬리.
- 비교 툴과 유닛 툴의 공통 조명/노출 및 포인트 라이트 통일.
- 바주카 길이 약 31.8% 증가, 등 쪽으로 낮춘 사선 거치.
- 6초 idle, blink/squint/bow/wave/victory를 추가해 최종 18동작.
- 찡그림에서 감은 눈 선이 겹치던 모프 보정.
- 원본과 비교한 피부·홍조 색 반응 보정, 얼굴 머리 그림자 0.22로 완화.

## 5. 루온 새 제작과 공통 FX
- D 수준의 제작 파이프라인을 분리해 모자 없는 네이비 남자 A를 새로 제작.
- 청록 눈·민트 띠·짧은 머리·전용 망토·미소·18클립 및 원본 비교 툴.
- 얼굴 그림자 농도 0.18로 완화.
- 공통 WeaponMuzzleFx: 쌍권총 교대 섬광, 바주카 사각 파동·블록 입자·연기.
- 사용자의 후면 가시성 요청에 따라 머리 바깥으로 확산 범위를 확대.
- 총구 로컬 앵커, 스킨 좌표 정렬, 클립 시간·일시정지·혼합 상태 동기화.

- 19개 미사용 모델/이전 툴 파일을 ZIP과 파일별 해시로 백업.
- 캐릭터 두 카드와 체형 두 버튼씩, 접는 동작 메뉴, 별도의 유닛·전투 목록.
- 동일 조명/시점에서 기존형과 3.5등신을 비교하는 통합 화면.
- 그룩봇 정기 확인 중지. 이후 채팅 지시만 따른다.
