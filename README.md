# Soos Arcade

## 기획툴 (정본)

기획은 `planner/` 기획툴에서 한다. `planner/data.json` 이 정본이다.
열기: `planner\기획툴_열기.bat` 더블클릭 → http://localhost:4174/
`기획서 내보내기` 를 누르면 `docs/기획서.md` 가 만들어진다. 다른 AI에게는 이 파일을 준다.
아래 docs의 20261010 문서들은 이전 세션 문서다. 참고만 한다.


외출 카드 여섯 장은 한 이야기다. 한 장씩 깨 나간다.
푸더덕과 비슷한 놀이는 03 입구의 후보다.
수스와 섞이지 않는 별도 프로젝트다.
위치는 `C:\soos-arcade` 이다. `C:\xoox` 안에는 두지 않는다.

로비와 기존 콘텐츠는 수스에 그대로 둔다.
이 폴더에는 외출 카드 기획과, 앞으로 이 프로젝트에서 새로 만들 파일만 둔다.

수스의 그림, 모델, 맵은 지금 복사해 두지 않았다.
카드나 게임에 쓸 파일이 정해지면, 그 파일만 여기로 가져온다.
