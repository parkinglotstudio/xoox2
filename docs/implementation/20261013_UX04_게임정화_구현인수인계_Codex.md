# UX04 실제 게임·기획툴 구현 인수인계

작성: Codex · 2026-10-13 23:08 KST · 원본 `C:\xoox-arcade`

## 시작 지시

이 프로젝트는 수스 정화숲/복셀 캐릭터·반려동물의 세계를 사용하는 XOOX 아케이드다. 초기 아이디어10종을 확정4대표+3통합 추가, 실제7게임과 생활형 마을침략으로 구성한다. 기획툴에서 로비/카드/각 게임을 실제 플레이하며 표를 조절한다. 소스 정본은 src/arcadeComplete, 표 정본은 assets/arcade/config-codex, 최신 서사/설명은 experience-v3.json(UX04 revision). 이전 src/arcade와 legacy는 보존본이다. 먼저 작업 보고서와 8개 계획 문서, data/handoff-baseline.v4.json을 읽고 현황/주장을 실제 실행과 대조하라.

## 실행

프로젝트 루트에서 `npm run dev -- --host 127.0.0.1 --port 5190 --strictPort`, 별도 터미널에서 `npm run planner`. 기획툴 http://localhost:4174/planner/, 플레이툴 /planner/play.html?part=p03. 실제 HTML은5190의 arcade-lobby.html, arcade-cards.html, arcade-game1~7.html. 침략은 arcade-lobby.html?planner=1&raid=1. UI 메시지 origin은 현재 localhost4174/5190 계약이다. 서버가 이미 실행중이면 포트 소유 프로세스를 확인하고 재사용한다.

## FPS와 입력 계약

p02는 BaseDefense를 새로 복제하지 않는다. GameApp에서 카메라 좌표 이동을 월드로 변환하고 yaw/fire/autoFire를 InputFrame에 넣는다. 조준 보조는 중앙18도·LOS·가까운 대상. 보조사격 끔이면 기본 사격은 fire 입력이 참일 때만. 빈 공간 발사도 실제 탄이다. 기본 사격3초/재장전2초, 범위 기술·시설은 별도 CD. 입력 다운로드에 이동/yaw/fire/autoFire와 명령·snapshot을 저장한다. 현재 기획툴은 기록 다운로드를 제공하며 완성된 리플레이 시청 UI를 새로 만들었다고 주장하지 않는다.

## 정화 계약

p01~6 environment progress는 환경 회복 연출/실제 셀 누적이며 별도 승리 제한이 아니다. p07의 승리 정화45%는 AdventureRules.cleaned가 정본. 결과 RunResult.purification은 전투 중 복원 비율, objective는 실제 모드별 목표다. 성공 후 지도 전체 밝힘은 별도 연출이다. 꽃/바닥은 길과 적 스탯을 바꾸지 않는다. 물/장애물/구멍은 canStand로 제외한다. p05는 방마다 reset하고 문이 열릴 때 완전복원. Blender 네비를 유지한다.

## 표와 밸런스

common.json: HP140/연사10·6스킬/3패시브·Lv14/보급18초·추가 시작1선택·starterSkills. rulesets.json: 코어520, 생존180초·피해0.75·회복0.65, 수색3무리/방, 호위560·2.8m/s, 복구45%/3초. campaign은5지역×7카드35미션. rulesets params에 쓰이지 않는 maxLevel을 다시 넣지 말고 common.growth를 수정한다. 기획툴 수치는 snapshot override, 영구 저장은 API whitelist를 따른다. 효과시험19종은 일반 슬롯 규칙과 별개이며 campaign에서는 금지. FPS/성장/범위 탄의 판정 경로를 확인하고 성공 스텁으로 교체하지 않는다.

## 자산과 Blender

기존 캐릭터4형태·5펫·49적·99유닛 카탈로그·VILLAGE03·시설/정화탑을 우선 재사용. 이미지 assets/arcade/art/UX03는 카드/시안 자산으로 실제 모델을 바꾸지 않는다. logo.png는 투명. 그림 프롬프트와 출처는 generation-1/2.json. 기존 UI 방향 시안을 실행화면이라고 표시하지 않는다.

Blender 재생성: `art-source/arcade/CODEX_COMPLETE/build_arcade_maps.py`와 `.../CODEX_EXPANSION/build_expansion_maps.py`. 프로젝트 루트를 scripts.parents[3]로 찾는다. CODEX_FOREST6 + CODEX_EXPANSION16 GLB. 같은 source를 Blender5.2 --background --python으로 실행해 현재 맵을 보완한다. 만든 map collider/room blocker/island bridge와 눈에 보이는 통로의 일치를 유지한다. 이전 파일은 docs/backups/20261013_UX_Codex.

## 검수 재현과 읽을 증거

`node node_modules/typescript/bin/tsc -p scripts/qa-codex-expansion/tsconfig.json --noEmit`은 현재 아케이드 범위 검사. scripts/qa-codex-ux04/README.md와5검수 스크립트. docs/reports/assets/20261013_UX04_Codex에7게임/4추가시드·35snapshot·효과·침략·실제터치·모바일좁은화면·실패/재시작·FPS 입력기록·그림로딩/캡처가 있다.

보고된 자동 한 판 시간은 실제 전투 틱의 자동 이동/카드 선택 결과. 사람의 메뉴/길찾기 체감 시간과 구별하라. 실패 UI에만HP0 주입했고 정상 승리를 주입하지 않았다. 터치는 Chromium의 실제 활성 포인터로 검수. 실제폰 성능/장시간 사람 플레이는 아직 별도다. 전체프로젝트 combatSkill TS7006은 과거 다른 소스 문제로 현재 아케이드 범위 밖. 소리/배포빌드/배포를 완료했다고 주장하지 않는다.

## 작업 절차

원본 C:\xoox-arcade만 작업하며 과거 C:\soos-arcade는 기록 경로. 사용자 지시로 그룩 체크는 현재 중지 상태다. 다른 담당의 파일/BOARD 행을 보존하고 자기 행·날짜/Codex 보고서로 기록한다. 커밋/푸시/다른AI 메시지는 사용자 요청 때만. 이 문서와 실제 코드가 다르면 근거를 보고하고 현행 snapshot·검수 결과로 수정한다. 구현 품질과 미검수를 명확히 구별하라.
