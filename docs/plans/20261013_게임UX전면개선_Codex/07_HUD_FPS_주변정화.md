# HUD · FPS 모바일 · 주변 정화 추가 명세

작성: Codex · 2026-10-13 · UX04 · 사용자 최신 5개 요청 반영

## 전투 화면 정보 순서

1. 위쪽: 이야기 제목, 시간/레벨, 도움말/일시정지.
2. 얇은 체력: 캐릭터·코어(또는 호위 수레), 경험치는 작은 선. 보스가 있을 때만 별도 HP.
3. 단 하나의 목표 패널: 지금 해야 할 일·남은 적/정화/복구 진행. 하단의 중복 목표·예고·기술 아이콘 열은 기본으로 숨긴다.
4. 가운데: 실제 전장. 단계 알림은 3.2초만 나타난다. 위험 예고는 실제 판정 시각과 연결한다.
5. 아래: 이동 패드, 현재 가능한 행동. 기술 보기 버튼을 눌러 장착 목록을 펼친다.

브리핑·카드·일시정지 때 입력과 전투 틱을 중단한다. HUD는 전투 상태를 읽으며 승리를 만들지 않는다. 360×640과 430×920 브라우저 화면에서 버튼 영역을 확인한다. 실제 기기 성능/손가락 사용성은 별도 사용자 검수다.

## 첫 10초

공통 표 growth.starterSkills에서 기술을 실제 Loadout에 넣는다. 장비가 없는 채로 시작하지 않는다. p01 화염 바주카 Lv2, p02 번개 바주카 Lv2, p03 서리 조각 Lv2, p04 대열 정화 폭탄 Lv1, p05 번개 사슬 Lv2, p06 서리 조각 Lv2, p07 서리 장막 Lv2. 기본 쌍권총 또는 체인 사격은 유지한다. 시작 브리핑에는 장비 그림·이름·효과를 설명하며 첫 카드 선택은 추가 장비/강화다. 공격 대상이 없어도 서리 조각의 회전은 볼 수 있다. 공격 기술은 실제 피해/둔화/폭발 경로를 사용한다.

## FPS

목적은 정화 코어를 3웨이브 동안 지키는 것이다. 준비는 기존 탑다운 시설 배치. 시작 후 1인칭 전환. 이동 패드는 카메라 기준 좌우/전후, 시점 패드는 yaw/pitch, 사격 버튼을 누르는 동안 기본 공격. PC는 WASD·화면 오른쪽 드래그·Space. 시점 변화와 사격은 동시에 사용할 수 있다.

초기 보조 사격 켬: 중앙 18도 시야의 가까운 적을 자동 사격. 토글로 끄면 사격 버튼/Space가 기본 공격을 제어한다. 빈 공간에서도 직접 사격은 발사되며 실제 투사체 판정이다. 정화 스킬/시설은 별도 자동 지원이다. 코어 방향·거리·재장전과 뒤쪽 적 경고를 제공한다. 캐릭터 HP 또는 코어 HP가 0이면 실패. 카메라 기능을 별도 전투 코드로 복제하지 않는다.

## 수스의 정화 정체성

기존 p07은 바닥 45%와 시설3곳을 실제로 복구하는 정화 게임이다. 추가로 p01~6은 이동/몬스터 정화가 주변 땅을 되살린다. PurificationField가 걸을 수 있는 격자만 생성하며 0.25초마다 이동 반경2.4m, 처치 반경3.6m(보스7m)를 복원한다. 물/장애물/공중섬 사이/구멍은 그리지 않는다. 색은 오염의 회보라 → 풀빛의 여러 색, 복원 셀에는 작은 블록 꽃이 돌아온다. p05는 방마다 진행을 새로 만들고 정화된 방 전체가 밝아진다. 최종 성공 후 전체 땅을 밝히는 연출은 전투 중 실제 복원 기록과 구별한다.

정화는 전투에서 실제 셀 상태를 누적한다. p03 목표에 환경 회복 진행이 보인다. 환경 진행률은 p01~6의 추가 승리 제한이 아니다. p07의 실제45% 조건은 기존 AdventureRules.cleaned가 정본이다. 정화 셀은 적 길·사거리·HP·충돌을 바꾸지 않는다. 셀은 약950개 상한, 꽃190개 상한, 두 InstancedMesh로 묶는다. 복구 기능과 성능 기준을 구별해 보고한다.
